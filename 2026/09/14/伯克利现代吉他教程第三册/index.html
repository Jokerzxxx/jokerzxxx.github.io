伯克利现代吉他教程（第三册）

伯克利现代吉他教程（第三册）

作者：William Leavitt（威廉·里维特）
译者：张博
全书共170页，伯克利音乐学院经典吉他教材第三册，高级阶段内容，深入讲解高级爵士和声、现代即兴技巧、复合节奏、现代音乐风格、创作编曲与专业演奏。

前言与教材说明

第三册定位

第三册是伯克利现代吉他教程的高级阶段，假设学习者已掌握前两册内容：

  • 熟练掌握横按和弦和多把位音阶
  • 理解七和弦和基础爵士和声
  • 具备基本即兴能力
  • 掌握各种吉他技巧
  • 有一定的音乐理论基础

第三册目标：

  • 掌握高级爵士和声与替代
  • 发展高级即兴技巧和个人风格
  • 掌握复合节奏和现代节奏感觉
  • 学习现代音乐风格（融合爵士、放克、摇滚等）
  • 培养创作和编曲能力
  • 达到专业演奏水平

学习建议

  • 前两册内容必须扎实，不要跳级
  • 第三册内容较难，需要更多时间消化
  • 多听现代爵士和融合音乐，培养听觉
  • 大量的即兴练习和录音回听
  • 分析大师的演奏和编曲
  • 尝试创作和改编
  • 与其他乐手合奏，提高合奏能力

第1部分 高级爵士和声

扩展和弦与变音和弦

扩展和弦：

  • 九和弦（9）、十一和弦（11）、十三和弦（13）
  • 大九（Maj9）、属九（9）、小九（m9）
  • 大十三（Maj13）、属十三（13）、小十三（m13）
  • 扩展音增加和声色彩和张力

变音属七和弦：

  • 属七和弦的变化音：
    • b9、#9、b5、#5、#11、b13
  • 7#9（亨德里克斯和弦）：1 3 5 b7 #9
  • 7b9：1 3 5 b7 b9
  • 7#5：1 3 #5 b7
  • 7b5：1 3 b5 b7
  • 7#9b13等组合变音
  • 变音增加紧张感，倾向解决

和弦 voicings 进阶：

  • Drop 2、Drop 3 voicings
  • 四度堆叠和弦（So What和弦）
  • 无根音和弦（爵士吉他常用）
  • 声部进行（Voice Leading）
  • 和弦旋律化（Chord Melody）
  • 各种把位的和弦按法

高级和声进行

ii-V-I的变体：

  • 基本ii-V-I：Dm7-G7-Cmaj7
  • 小调ii-V-i：Dm7b5-G7b9-Cm7
  • 三全音替代：Dm7-Db7-Cmaj7
  • 次级属和弦：II7-V7-I（A7-Dm7-G7-Cmaj7）
  • 延迟解决：Dm7-G7-G7b9-Cmaj7
  • 各种经过和弦和装饰

节奏变化（Rhythm Changes）：

  • 基于《I Got Rhythm》的和弦进行
  • A段：I-vi-ii-V / I-vi-ii-V / I-bVII-bVI-V / I-VI-ii-V
  • B段：II7-II7 / bVII7-bVII7 / bVI7-bVI7 / V7-V7
  • 爵士标准曲常用结构
  • 练习各调的Rhythm Changes

其他高级进行：

  • 五度循环进行
  • chromatic mediant（半音中音关系）
  • modal interchange（调式互换）
  • 持续音（Pedal Point）
  • 多调性（Polytonality）

和声分析与编曲

和声分析方法：

  • 确定调性
  • 标记和弦功能（I、ii、V等）
  • 识别替代和弦和经过和弦
  • 分析转调和调式互换
  • 理解和声进行的逻辑和张力解决

吉他编曲：

  • Chord Melody（和弦旋律）：同时演奏旋律和和弦
  • 选择合适的和弦voicings
  • 安排低音线条
  • 设计前奏、间奏、尾奏
  • 注意声部进行和连接
  • 适应吉他的音域和指法

第2部分 高级即兴技巧

音阶与和弦的高级对应

属七和弦的音阶选择：

  • 混合利底亚（Mixolydian）：基础属七音阶
  • 布鲁斯音阶：布鲁斯色彩
  • 半减音阶（Half-Diminished）：b9 b13
  • 全音阶（Whole Tone）：#5 #11
  • 减音阶（Diminished）：b9 #9 #11 b13（对称音阶）
  • Altered音阶（Super Locrian）：b9 #9 b5 #5（全变音）
  • Lydian Dominant：#11（融合爵士常用）

其他和弦的音阶：

  • 大七和弦：大调音阶、利底亚（#4）
  • 小七和弦：多利亚（大六度）、小调五声、布鲁斯
  • 半减七：洛克里亚、半减音阶
  • 减七：减音阶（对称）
  • 增三：全音阶
  • sus4：多利亚、混合利底亚

音阶练习高级方法：

  • 音阶模进（1231 2342 3453…）
  • 三度、四度、六度、七度音程
  • 音阶+和弦音强调
  • 经过音和邻音练习
  • 各种节奏型的音阶练习
  • 跨弦音阶练习

即兴的节奏与乐句

节奏即兴：

  • 节奏的变化比音符更重要
  • 切分、附点、三连音、十六分音符
  • 留白（Rest）的使用
  • 重音移位
  • 跨小节节奏
  • 复合节奏（Polyrhythm）

乐句构建：

  • 动机（Motif）发展
  • call-and-response（呼与应）
  • 问答式乐句
  • 模进发展
  • 变奏发展
  • 高潮设计
  • 乐句的呼吸和结构

即兴练习方法：

  • 限制练习：只用几个音、只用一种节奏
  • 主题变奏：基于一个动机发展
  • 跟伴奏即兴（Backing Track）
  • 转录大师独奏（Transcription）
  • 分析大师的乐句和节奏
  • 录音回听，自我批评
  • 与其他乐手jam

现代即兴概念

Outside演奏：

  • 在和弦外演奏，制造张力
  • 半音移位
  • 替代音阶
  • 多调性
  • 紧张与解决的平衡
  • 现代爵士常用

旋律小调体系：

  • 旋律小调（上行）：1 2 b3 4 5 6 7
  • 旋律小调的七个调式：
    • Melodic Minor（I）：小大七和弦
    • Dorian b2（II）：Phrygian #6
    • Lydian Augmented（III）：增三+大七
    • Lydian Dominant（IV）：属七#11（融合爵士）
    • Mixolydian b6（V）：属七b13
    • Half-Diminished（VI）：半减七
    • Altered（VII）：属七全变音
  • 现代爵士和融合爵士核心音阶体系

其他现代概念：

  • 四度堆叠旋律
  • 无调性即兴
  • 随机/偶然音乐
  • 极简主义
  • 氛围音乐
  • 电子音乐元素

第3部分 复合节奏与现代节奏

复合节奏

复合节奏概念：

  • 同时出现不同的节奏型
  • 2对3、3对4、4对5等
  • 增加节奏的复杂度和张力
  • 现代音乐常用

常见复合节奏：

  • 2对3（Hemiola）：三拍里弹两拍的感觉
  • 3对4：四拍里弹三拍
  • 4对5、5对6等
  • 奇数拍（5/4、7/8、9/8等）
  • 节拍移位（Metric Modulation）

复合节奏练习：

  • 节拍器练习不同拍号
  • 一只手弹一种节奏，另一只手弹另一种
  • 跨小节的节奏型
  • 跟奇数拍伴奏即兴
  • 听现代爵士和融合音乐中的复合节奏

现代节奏风格

融合爵士（Fusion）：

  • 爵士+摇滚+放克+电子
  • 复杂的和声和节奏
  • 电吉他效果器大量使用
  • 代表人物：Miles Davis、John McLaughlin、Allan Holdsworth、Pat Metheny
  • 代表曲目：《So What》（后期）、《Birds of Fire》

放克（Funk）：

  • 强调16分音符的切分节奏
  • 吉他以节奏为主，制音和切音
  • 单音riff和和弦riff
  • 代表人物：James Brown、Parliament-Funkadelic、Prince
  • 代表曲目：《Sex Machine》《Give Up the Funk》

现代摇滚/金属：

  • 复杂的riff和节奏
  • 降弦和特殊调弦
  • 速弹和点弦
  • 奇数拍和复合节奏
  • 代表：Dream Theater、Meshuggah、Animals as Leaders

拉丁节奏：

  • 波萨诺瓦（Bossa Nova）
  • 桑巴（Samba）
  • 萨尔萨（Salsa）
  • 弗拉门戈（Flamenco）
  • 各种拉丁节奏型和Clave

第4部分 现代吉他技巧

高级电吉他技巧

速弹（Sweep Picking）：

  • 扫拨，上下扫过琴弦
  • 琶音速弹
  • 右手手腕动作
  • 左手配合
  • 常见于新古典金属和融合爵士
  • 代表：Yngwie Malmsteen、Jason Becker

点弦（Tapping）：

  • 右手手指点按指板
  • 双手点弦
  • 点弦琶音
  • 点弦音阶
  • 代表：Eddie Van Halen、Stanley Jordan

摇把技巧：

  • 颤音（Vibrato）
  • 俯冲（Dive Bomb）
  • 上提
  • 摇把泛音
  • 双摇系统
  • 代表：Jimi Hendrix、Eddie Van Halen、Steve Vai

泛音技巧：

  • 自然泛音（Natural Harmonics）
  • 人工泛音（Artificial Harmonics / Pinch Harmonics）
  • 摇把泛音
  • 点弦泛音
  • 泛音旋律
  • 代表：Roy Buchanan、Billy Gibbons

其他高级技巧：

  • 八指点弦
  • 滑棒（Slide）
  • E-Bow
  • 准备吉他（Prepared Guitar）
  • 各种效果器创意使用

指弹高级技巧

现代指弹：

  • 打板（Percussive）：敲击琴身产生打击乐效果
  • 拍弦（Slap）：右手拍击琴弦
  • 点弦在指弹中的应用
  • 泛音旋律
  • 调弦变化（Open Tuning、DADGAD等）
  • 代表：Tommy Emmanuel、Andy McKee、Kotaro Oshio（押尾桑）

古典吉他技巧：

  • 轮指（Tremolo）：无名指-中指-食指-拇指快速交替
  • 圆滑音（Ligado）：击勾弦
  • 双音和多音
  • 音阶和琶音
  • 代表：Andrés Segovia、John Williams

效果器与音色

常用效果器：

  • 过载（Overdrive）/失真（Distortion）/法兹（Fuzz）
  • 延迟（Delay）：模拟延迟、数字延迟、磁带延迟
  • 混响（Reverb）：弹簧、板式、大厅、房间
  • 调制：合唱（Chorus）、相位（Phaser）、镶边（Flanger）、颤音（Tremolo）
  • 哇音（Wah）
  • 压缩（Compressor）
  • 均衡（EQ）
  • 音量踏板（Volume Pedal）
  • 循环（Looper）

音色设计：

  • 信号链顺序
  • 单块效果器组合
  • 综合效果器
  • 音箱模拟
  • 录音音色
  • 现场音色
  • 个人音色风格的培养

第5部分 创作与编曲

作曲基础

旋律写作：

  • 动机发展
  • 乐句结构（起承转合）
  • 旋律轮廓
  • 节奏设计
  • 调式选择
  • 旋律与歌词的配合（歌曲写作）

和声写作：

  • 和弦进行设计
  • 张力与解决
  • 转调和调式互换
  • 替代和弦
  • 和声节奏
  • 贝斯线条设计

曲式结构：

  • 流行歌曲：AABA、Verse-Chorus、Verse-Chorus-Bridge
  • 爵士：AABA、ABAC、12小节布鲁斯、Rhythm Changes
  • 古典：奏鸣曲式、回旋曲、变奏曲
  • 现代：自由曲式、概念专辑

吉他编曲

独奏编曲：

  • Chord Melody编曲
  • 指弹编曲
  • 选择调
  • 安排旋律、和弦、低音
  • 设计前奏/间奏/尾奏
  • 技巧运用
  • 指法优化

乐队编曲：

  • 吉他在乐队中的角色
  • 节奏吉他与主音吉他
  • 与其他乐器的配合
  • 声部安排
  • 动态对比
  • 编曲的层次感

即兴创作

即兴作曲：

  • 在乐器上即兴创作旋律
  • 和弦进行上的即兴旋律
  • 动机发展
  • 录音捕捉灵感
  • 整理和发展即兴片段

创作练习：

  • 每天写一个动机
  • 限制创作（只用三个音、只用一种节奏）
  • 模仿风格创作
  • 改编现有歌曲
  • 与其他乐手合作创作
  • 记录灵感

第6部分 专业演奏与音乐事业

合奏与乐队

合奏技巧：

  • 听其他乐手
  • 保持稳定的时间感
  • 音量平衡
  • 互动与呼应
  • 留白与空间
  • 支持与独奏的平衡

乐队角色：

  • 节奏吉他：和声与节奏基础
  • 主音吉他：旋律与独奏
  • 与贝斯和鼓的配合
  • 与键盘/管乐的配合
  • 与主唱的配合

排练与演出：

  • 有效排练方法
  • 曲目安排
  • 现场调试
  • 舞台表现
  • 设备管理
  • 应急处理

音乐事业

职业发展路径：

  • 演奏家（独奏/乐队）
  • 录音室乐手
  • 音乐教师
  • 作曲/编曲
  • 音乐制作
  • 音乐教育
  • 音乐治疗
  • 音乐管理

技能提升：

  • 持续学习和练习
  • 多听各种音乐
  • 学习其他乐器
  • 学习音乐理论和历史
  • 学习录音和制作
  • 学习商业知识

人脉与机会：

  • 多演出，多jam
  • 结识其他乐手
  • 利用社交媒体
  • 参加比赛和音乐节
  • 录制Demo和专辑
  • 建立个人品牌

读书笔记总结

《伯克利现代吉他教程（第三册）》是伯克利音乐学院经典吉他教材的高级篇，深入讲解高级爵士和声、现代即兴技巧、复合节奏、现代音乐风格、创作编曲与专业演奏。

全书知识脉络：

部分 主题 核心内容
第1部分 高级爵士和声 扩展和弦、变音属七、Drop voicings、ii-V-I变体、Rhythm Changes、和声分析、Chord Melody编曲
第2部分 高级即兴技巧 音阶与和弦高级对应（Altered/Lydian Dominant/旋律小调体系）、节奏即兴、乐句构建、Outside演奏、转录分析
第3部分 复合节奏与现代节奏 2对3/3对4复合节奏、奇数拍、节拍移位、融合爵士、放克、现代摇滚/金属、拉丁节奏
第4部分 现代吉他技巧 速弹扫拨、点弦、摇把、泛音、现代指弹打板、古典轮指、效果器与音色设计
第5部分 创作与编曲 旋律写作、和声写作、曲式结构、独奏编曲、乐队编曲、即兴创作、创作练习
第6部分 专业演奏与音乐事业 合奏技巧、乐队角色、排练演出、职业发展路径、技能提升、人脉机会

学习建议：

  • 第三册是高级教材，必须在前两册扎实的基础上学习
  • 高级爵士和声需要大量分析和实践，不要只记理论
  • 即兴是核心，大量的跟伴奏练习和录音回听是提高的关键
  • 转录大师独奏（Transcription）是学习即兴的最有效方法
  • 复合节奏和现代风格需要多听多练，培养节奏感
  • 创作和编曲需要实践，从简单的改编开始
  • 多与其他乐手合奏，提高合奏能力和音乐交流
  • 建立个人风格，不要只模仿，要在学习基础上发展自己的声音
  • 音乐是终身学习，保持好奇心和热情
  • 三册学完后，继续深入学习自己感兴趣的风格和方向

这本书适合有扎实吉他基础、希望达到专业演奏水平的学习者，是现代吉他学习的巅峰教材。
