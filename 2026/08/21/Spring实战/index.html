Spring实战

Spring实战（第6版）

作者：Craig Walls
全书共约14章，574页，Spring框架的经典实战教材，以Spring Boot为基础，涵盖Spring核心、Web开发、数据访问、安全、REST、消息、响应式编程等全栈内容。

第1章 Spring入门

什么是Spring

Spring是一个开源的Java/Java EE应用框架，由Rod Johnson于2003年创建。

  • 核心目标：简化Java企业级开发
  • 核心特性：
    • 依赖注入（DI）/控制反转（IoC）
    • 面向切面编程（AOP）
    • 声明式事务
    • 一站式框架（Web、数据、安全、消息等）

Spring的演进：

  • Spring 1.x：XML配置，核心IoC/AOP
  • Spring 2.x：注解支持（@Component、@Autowired）
  • Spring 3.x：Java配置（@Configuration、@Bean），SpEL
  • Spring 4.x：WebSocket、 messaging、条件注解
  • Spring 5.x：响应式编程（WebFlux）、Java 8+支持、Kotlin支持
  • Spring Boot：简化Spring应用创建和运行，自动配置、起步依赖、内嵌服务器

初始化Spring应用程序

Spring Boot：

  • 简化Spring应用开发
  • 自动配置（Auto-Configuration）
  • 起步依赖（Starter Dependencies）
  • 内嵌服务器（Tomcat/Jetty/Undertow）
  • Actuator：生产级监控
  • 无需XML配置

创建Spring Boot项目：

  • Spring Initializr（start.spring.io）
  • Spring Tool Suite（STS）
  • IntelliJ IDEA Ultimate
  • 命令行：Spring Boot CLI

项目结构：

  • src/main/java/：Java源码
  • src/main/resources/：资源文件
    • application.properties / application.yml：配置文件
    • static/：静态资源
    • templates/：模板文件
  • src/test/java/：测试代码
  • pom.xml / build.gradle：构建配置

主应用类：

  • @SpringBootApplication = @Configuration + @EnableAutoConfiguration + @ComponentScan

编写Spring应用程序

处理Web请求：

  • @Controller：控制器
  • @GetMapping：处理GET请求
  • 返回视图名

定义视图：

  • Thymeleaf模板引擎（Spring Boot默认）
  • src/main/resources/templates/home.html
  • 自然模板，可直接在浏览器打开

测试控制器：

  • @SpringBootTest：Spring Boot测试
  • MockMvc：模拟HTTP请求
  • @WebMvcTest：仅测试Web层

构建并运行：

  • mvn spring-boot:run 或 ./gradlew bootRun
  • 打包：mvn package 生成可执行JAR
  • 运行：java -jar target/myapp.jar

Spring Boot DevTools：

  • 开发工具
  • 自动重启（类变更时）
  • LiveReload（资源变更时自动刷新浏览器）
  • 开发时使用，生产禁用

俯瞰Spring风景线

Spring核心框架：

  • Core：IoC容器、DI、AOP
  • Context：应用上下文、事件
  • SpEL：表达式语言
  • Web：Spring MVC、WebSocket
  • Data Access：JDBC、ORM、事务

Spring Boot：

  • 自动配置、起步依赖、内嵌服务器、Actuator

Spring Data：

  • 数据访问统一抽象
  • Spring Data JPA、MongoDB、Redis、Cassandra等
  • Repository抽象、自动生成实现

Spring Security：

  • 认证和授权
  • 保护Web应用、REST API
  • OAuth2、JWT

Spring Integration和Spring Batch：

  • Integration：企业集成模式、消息
  • Batch：批处理

Spring Cloud：

  • 微服务架构
  • 服务发现、配置中心、断路器、网关、链路追踪

Spring Native：

  • GraalVM原生镜像
  • 快速启动、低内存占用

第2章 开发Web应用程序

展示信息

建立领域实体：

  • Lombok @Data：自动生成getter/setter/toString/equals/hashCode
  • 领域模型：实体、值对象

创建控制器类：

  • @Controller：控制器
  • @RequestMapping：类级请求映射
  • @GetMapping：方法级GET映射
  • Model：传递数据到视图

设计视图：

  • Thymeleaf模板
  • 表达式：${...}变量、*{...}对象属性、#{...}消息
  • 属性：th:text、th:each、th:if、th:href、th:action
  • 表单：th:object、th:field

处理表单提交

  • @PostMapping：处理POST请求
  • @Valid：触发验证
  • Errors / BindingResult：验证结果
  • redirect:：重定向

验证表单输入

声明验证规则：

  • Bean Validation（JSR-380）
  • 注解：
    • @NotNull：非空
    • @NotEmpty：非空且非空字符串/集合
    • @NotBlank：非空白
    • @Size：大小范围
    • @Min / @Max：数值范围
    • @Pattern：正则匹配
    • @Email：邮箱格式
    • @Valid：级联验证

在表单绑定时执行验证：

  • @Valid注解触发
  • Errors / BindingResult获取错误
  • 控制器方法参数顺序：@Valid对象后紧跟Errors

显示验证错误：

  • Thymeleaf：th:errors、th:errorclass
  • #fields.hasErrors('field')、#fields.errors('field')
  • 全局错误：#fields.hasErrors('*')

使用视图控制器

ViewControllerRegistry：

  • 简单页面无需控制器逻辑
  • 直接映射URL到视图

选择视图模板库

Spring Boot支持多种模板引擎：

  • Thymeleaf：默认推荐，自然模板，HTML可直接打开
  • FreeMarker：传统模板引擎
  • Mustache：逻辑无关模板
  • Groovy Templates：Groovy模板
  • JSP：不推荐（限制多，Spring Boot支持有限）

缓存模板：

  • 生产环境缓存模板（默认）
  • 开发环境禁用缓存：spring.thymeleaf.cache=false
  • DevTools自动禁用缓存

第3章 处理数据

使用JDBC读写数据

为持久化改造领域实体：

  • 实体类映射数据库表
  • 字段映射列
  • ID字段

使用JdbcTemplate：

  • @Repository：仓储组件
  • JdbcTemplate：简化JDBC操作
  • query：查询，RowMapper映射结果
  • queryForObject：查询单个对象
  • update：插入/更新/删除
  • 自动处理资源（连接、语句、结果集）

定义schema并预加载数据：

  • schema.sql：建表脚本
  • data.sql：初始数据
  • Spring Boot启动时自动执行
  • 配置：spring.sql.init.mode=always

插入数据：

  • jdbc.update执行INSERT
  • 参数占位符?
  • 返回影响行数

使用Spring Data JDBC

添加Spring Data JDBC：

  • 起步依赖：spring-boot-starter-data-jdbc
  • 简化JDBC数据访问

定义Repository接口：

  • 继承CrudRepository<T, ID>
  • 自动获得CRUD方法：save、findById、findAll、delete、count等
  • 无需实现类，Spring Data自动生成

为持久化注解领域实体：

  • @Table：映射表名
  • @Id：主键
  • @Column：列映射
  • Spring Data JDBC比JPA简单，无复杂映射

使用CommandLineRunner预加载数据：

  • 应用启动后执行
  • 用于初始化数据

使用Spring Data JPA持久化数据

添加Spring Data JPA：

  • 起步依赖：spring-boot-starter-data-jpa
  • Hibernate作为默认JPA实现

注解领域实体：

  • @Entity：JPA实体
  • @Id：主键
  • @GeneratedValue：主键生成策略
  • @Enumerated：枚举映射
  • @ManyToMany、@OneToMany、@ManyToOne、@OneToOne：关联映射
  • @Table：表名
  • @Column：列映射

声明JPA Repository：

  • 同Spring Data JDBC
  • 继承CrudRepository或JpaRepository
  • 自动生成实现

自定义Repository：

  • 方法名派生查询：
    • findBy...：按条件查询
    • readBy...、getBy...
    • countBy...：计数
    • deleteBy...：删除
    • 关键字：And、Or、Between、LessThan、GreaterThan、Like、IgnoreCase、OrderBy等
  • @Query注解：自定义JPQL/SQL查询
  • 分页排序：Pageable、Sort参数，返回Page<T>

第4章 处理非关系型数据

使用Cassandra Repository

启用Spring Data Cassandra：

  • 起步依赖：spring-boot-starter-data-cassandra
  • 配置：spring.data.cassandra.keyspace-name、contact-points、port

理解Cassandra数据模型：

  • 列族（Column Family）= 表
  • 分区键（Partition Key）：数据分布
  • 集群列（Clustering Column）：分区内排序
  • 宽行、高可用、最终一致性
  • 适合大规模写入、时间序列数据

Cassandra持久化实体映射：

  • @Table：表映射
  • @PrimaryKey：主键
  • @PrimaryKeyColumn：主键列（分区键/集群列）
  • @Column：列映射
  • @CassandraType：类型映射

编写Cassandra Repository：

  • 继承CassandraRepository
  • 方法名派生查询（有限制，需考虑分区键）
  • @Query：CQL查询

编写MongoDB Repository

启用Spring Data MongoDB：

  • 起步依赖：spring-boot-starter-data-mongodb
  • 配置：spring.data.mongodb.uri、host、port、database

MongoDB持久化实体映射：

  • @Document：文档映射
  • @Id：主键（MongoDB的_id）
  • @Field：字段映射
  • @Indexed：索引
  • @DBRef：引用其他文档
  • 灵活Schema，嵌套文档

编写MongoDB Repository接口：

  • 继承MongoRepository<T, ID>
  • 方法名派生查询
  • @Query：JSON查询
  • 聚合查询：@Aggregation

MongoTemplate：

  • 更灵活的MongoDB操作
  • Criteria查询、聚合管道
  • 适合复杂查询

第5章 Spring安全

启用Spring Security

添加依赖：

  • 起步依赖：spring-boot-starter-security
  • 添加后自动启用安全保护
  • 默认用户：user，密码在启动日志中

Spring Security核心：

  • 认证（Authentication）：验证用户身份
  • 授权（Authorization）：控制用户访问权限
  • 过滤器链（Filter Chain）：一系列Servlet过滤器
  • 安全上下文（SecurityContext）：存储认证信息

配置身份验证

内存用户详情服务：

  • {noop}：密码前缀，表示无编码（仅测试用）
  • {bcrypt}：BCrypt编码
  • 角色/权限

自定义用户身份验证：

  • 实现UserDetailsService接口
  • 从数据库加载用户
  • UserDetails接口：用户名、密码、权限、是否启用等
  • User类：默认实现

密码编码器：

  • PasswordEncoder接口
  • BCryptPasswordEncoder：推荐，BCrypt算法
  • NoOpPasswordEncoder：不编码（仅测试）
  • Pbkdf2PasswordEncoder、SCryptPasswordEncoder
  • 密码前缀：{bcrypt}、{noop}等

保护Web请求

保护请求：

  • authorizeRequests：授权配置
  • antMatchers：路径匹配
  • hasRole / hasAnyRole：角色要求
  • hasAuthority / hasAnyAuthority：权限要求
  • permitAll：允许所有
  • authenticated：需认证
  • denyAll：拒绝所有

创建自定义登录页面：

  • formLogin().loginPage("/login")
  • 登录表单：用户名、密码
  • POST到/login
  • 登录失败参数：?error
  • 登出：POST到/logout

登出：

  • logout().logoutSuccessUrl("/")
  • 清除SecurityContext
  • 使Session失效

启用第三方验证：

  • OAuth2登录：oauth2Login()
  • 配置客户端：spring.security.oauth2.client.registration
  • 支持Google、GitHub、Facebook等
  • OpenID Connect

阻止跨站请求伪造攻击：

  • CSRF保护默认启用
  • 表单需包含CSRF token（Thymeleaf自动添加）
  • REST API可禁用：csrf().disable()（但需其他保护）

启用方法级别保护

@PreAuthorize / @PostAuthorize：

  • 方法级安全
  • @EnableGlobalMethodSecurity(prePostEnabled=true)启用
  • @PreAuthorize("hasRole('ADMIN')")：调用前检查
  • @PostAuthorize：调用后检查返回值
  • SpEL表达式

了解您的用户

获取认证用户：

  • SecurityContextHolder.getContext().getAuthentication()
  • Principal参数注入
  • @AuthenticationPrincipal注解
  • Authentication对象：用户名、权限、详情

第6章 使用配置属性

微调自动配置

覆盖自动配置的Bean：

  • 自定义Bean覆盖自动配置的Bean
  • @ConditionalOnMissingBean：仅在不存在时创建
  • 自定义数据源、视图解析器等

使用属性文件配置：

  • application.properties / application.yml
  • 通用属性：
    • server.port：端口
    • spring.datasource.url：数据库URL
    • spring.datasource.username/password
    • spring.jpa.hibernate.ddl-auto：DDL策略
    • spring.thymeleaf.cache：模板缓存
    • logging.level.*：日志级别

Profile特定配置：

  • application-{profile}.properties
  • 激活Profile：spring.profiles.active=dev
  • @Profile注解：特定Profile才创建Bean
  • 多环境配置：dev、test、prod

创建自定义配置属性

@ConfigurationProperties：

  • @ConfigurationProperties(prefix="xxx")：绑定属性前缀
  • 属性名对应字段名
  • 类型安全
  • @Component注册为Bean，或@EnableConfigurationProperties启用

使用配置属性：

  • 注入Bean使用
  • application.yml中配置：
  • 宽松绑定：pageSize、page-size、PAGE_SIZE都可

属性元数据：

  • META-INF/spring-configuration-metadata.json
  • IDE自动补全、提示
  • spring-boot-configuration-processor自动生成

配置属性的高级用法

占位符：

  • ${...}引用其他属性
  • ${app.name:default}：带默认值
  • 环境变量、系统属性

随机值：

  • ${random.value}、${random.int}、${random.long}
  • ${random.int(100)}、${random.int[10,20]}

命令行参数：

  • --server.port=8080
  • 优先级高于配置文件

环境变量：

  • SERVER_PORT=8080
  • 大写、下划线替换点和短横线

配置优先级（从高到低）：

  1. 命令行参数
  2. SPRING_APPLICATION_JSON
  3. ServletConfig/ServletContext
  4. JNDI
  5. Java系统属性
  6. 操作系统环境变量
  7. application-{profile}.properties
  8. application.properties
  9. @PropertySource
  10. 默认值

第7章 创建REST服务

RESTful API设计

REST原则：

  • 资源为中心
  • HTTP方法表示操作：GET（查询）、POST（创建）、PUT（更新）、PATCH（部分更新）、DELETE（删除）
  • 状态码表示结果：200、201、204、400、401、403、404、500
  • 无状态
  • HATEOAS（超媒体驱动）

Spring MVC创建REST

@RestController：

  • 控制器+响应体
  • = @Controller + @ResponseBody
  • 返回对象自动序列化为JSON

HTTP方法映射：

  • @GetMapping、@PostMapping、@PutMapping、@PatchMapping、@DeleteMapping
  • @RequestMapping

路径变量：

  • @PathVariable
  • /api/orders/{id}

请求体：

  • @RequestBody
  • JSON反序列化为对象

响应状态：

  • @ResponseStatus
  • ResponseEntity：自定义状态码、头、体

超媒体与HATEOAS

Spring HATEOAS：

  • 资源表示包含链接
  • EntityModel<T>、CollectionModel<T>
  • WebMvcLinkBuilder构建链接
  • linkTo()、methodOn()、withRel()、withSelfRel()

数据REST

Spring Data REST：

  • 自动将Spring Data Repository暴露为REST API
  • 起步依赖：spring-boot-starter-data-rest
  • 自动生成CRUD端点
  • 支持分页、排序、搜索、关联
  • 自定义：@RepositoryRestResource、@RestResource

REST API安全

  • 无状态认证：JWT、OAuth2
  • HttpBasic：HTTP Basic认证
  • SessionCreationPolicy.STATELESS：无状态
  • CSRF禁用（REST API）

第8章 异步消息

异步消息概述

消息模式：

  • 点对点（P2P）：队列，一个消息一个消费者
  • 发布/订阅（Pub/Sub）：主题，一个消息多个订阅者

消息优势：

  • 解耦（生产者消费者不直接通信）
  • 异步（非阻塞）
  • 削峰（缓冲高峰流量）
  • 可靠（消息持久化、确认机制）

JMS

Java消息服务：

  • Java EE消息标准
  • 起步依赖：spring-boot-starter-activemq（ActiveMQ）
  • JmsTemplate：发送/接收消息
  • @JmsListener：监听消息
  • 消息转换器：MappingJackson2MessageConverter（JSON）

RabbitMQ

AMQP实现：

  • 高级消息队列协议
  • 起步依赖：spring-boot-starter-amqp
  • 核心概念：
    • Exchange：交换机，接收消息，路由到队列
    • Queue：队列，存储消息
    • Binding：绑定，交换机到队列的路由规则
    • Routing Key：路由键
  • Exchange类型：Direct、Fanout、Topic、Headers
  • RabbitTemplate：发送/接收
  • @RabbitListener：监听
  • 消息确认、重试、死信队列

Kafka

分布式流平台：

  • 高吞吐、可扩展、持久化
  • 起步依赖：spring-kafka
  • 核心概念：
    • Topic：主题
    • Partition：分区（并行、有序）
    • Offset：偏移量
    • Producer/Consumer
    • Consumer Group：消费者组
  • KafkaTemplate：发送
  • @KafkaListener：监听
  • 批量消费、事务、 exactly-once

第9章 集成Spring

Spring Integration

企业集成模式（EIP）：

  • 起步依赖：spring-boot-starter-integration
  • 核心组件：
    • Message：消息（头+体）
    • Channel：消息通道
    • Endpoint：端点（转换器、路由器、过滤器、分离器、聚合器等）
    • Gateway：网关
  • 配置：Java DSL、XML、注解
  • 适配器：文件、HTTP、JMS、Mail、TCP/UDP等

Spring Batch

批处理框架：

  • 起步依赖：spring-boot-starter-batch
  • 核心概念：
    • Job：作业
    • Step：步骤
    • ItemReader：读
    • ItemProcessor：处理
    • ItemWriter：写
    • JobRepository：作业仓库
    • JobLauncher：作业启动器
  • chunk-oriented处理
  • 跳过、重试、重启
  • 作业监控

第10章 响应式Spring

响应式编程

Reactive Streams：

  • 异步非阻塞、背压
  • 核心接口：Publisher、Subscriber、Subscription、Processor
  • Project Reactor：Spring默认响应式库
    • Mono<T>：0或1个元素
    • Flux<T>：0到N个元素
    • 操作符：map、flatMap、filter、zip、merge等

Spring WebFlux

响应式Web框架：

  • 起步依赖：spring-boot-starter-webflux
  • 两种编程模型：
    • 注解式：@RestController、@RequestMapping（同Spring MVC，但返回Mono/Flux）
    • 函数式：RouterFunction、HandlerFunction
  • 非阻塞、事件驱动
  • Netty服务器（默认）
  • 响应式客户端：WebClient（替代RestTemplate）

响应式数据访问

  • Spring Data Reactive：
    • R2DBC：响应式关系数据库
    • Spring Data MongoDB Reactive
    • Spring Data Cassandra Reactive
    • Redis Reactive
  • Repository返回Mono/Flux

响应式安全

  • Spring Security响应式支持
  • @EnableWebFluxSecurity
  • SecurityWebFilterChain
  • 响应式认证授权

第5章 Spring安全 认证授权、用户详情服务、密码编码器、请求保护、登录登出、CSRF、OAuth2
第6章 配置属性 自动配置微调、application.yml、Profile、@ConfigurationProperties、配置优先级
第7章 REST服务 @RestController、HTTP方法、ResponseEntity、HATEOAS、Spring Data REST
第8章 异步消息 JMS、RabbitMQ/AMQP、Kafka、消息模板、监听器
第9章 集成 Spring Integration企业集成模式、Spring Batch批处理
第10章 响应式编程 Reactor、Mono/Flux、Spring WebFlux、WebClient、响应式数据访问

学习建议：

  • 第1-2章是基础，必须掌握Spring Boot和Spring MVC
  • 第3-4章是数据访问，JPA是重点
  • 第5章安全是Web应用必备
  • 第6章配置属性是Spring Boot核心特性
  • 第7章REST服务是后端开发重点
  • 第8章消息是微服务架构常用
  • 第9章集成是企业应用场景
  • 第10章响应式是Spring 5新特性，适合高并发场景
  • 学习时一定要动手实践，Spring Boot快速启动方便实验
  • 配合官方文档和Spring Guides学习
  • 注意：本书基于Spring Boot 2.x，Spring Boot 3.x有变化（Jakarta EE、Java 17+）

这本书适合Java后端开发者、Spring初学者和希望系统学习Spring生态的开发者阅读，是Spring领域最经典的实战教材之一。
