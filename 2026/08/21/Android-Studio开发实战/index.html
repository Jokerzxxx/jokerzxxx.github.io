Android Studio开发实战

Android Studio开发实战：从零基础到App上线（第3版）

作者：欧阳燊
全书共约15章，658页，以Android Studio为开发工具，从零基础开始，通过大量实战项目讲解Android App开发，涵盖控件、组件、存储、自定义控件、事件、动画、网络、多媒体、应用上线等全流程。

第1章 Android开发环境搭建

Android开发简介

Android是Google开发的基于Linux的开源移动操作系统。

  • 应用层：Java/Kotlin编写的应用
  • 应用框架层：Java API框架
  • 系统运行库层：C/C++库 + ART虚拟机
  • HAL：硬件抽象层
  • Linux内核：驱动、进程管理、内存管理

Android开发特点：

  • 碎片化严重（不同厂商、不同版本、不同屏幕尺寸）
  • 开发语言：Java（传统）、Kotlin（官方推荐）
  • 开发工具：Android Studio（官方IDE，基于IntelliJ IDEA）
  • 构建工具：Gradle

搭建Android Studio开发环境

JDK安装：

  • Android Studio自带JDK（JetBrains Runtime），无需单独安装
  • 也可使用独立JDK 8/11/17

Android Studio安装：

  • 从官网下载安装包
  • 安装时选择Android SDK、Android Virtual Device、Intel HAXM
  • 首次启动下载SDK组件

SDK配置：

  • SDK Platform：不同Android版本的SDK平台
  • SDK Tools：构建工具、平台工具、模拟器镜像
  • SDK Manager管理SDK组件
  • 配置ANDROID_HOME环境变量

Gradle配置：

  • Android Studio自带Gradle
  • 项目使用Gradle Wrapper（gradlew），自动下载指定版本Gradle
  • 国内可配置阿里云镜像加速依赖下载

创建并编译App工程

创建项目：

  • New Project → 选择模板（Empty Activity、Basic Activity等）
  • 配置：
    • Name：应用名称
    • Package name：包名（反向域名，如com.example.myapp）
    • Save location：保存路径
    • Language：Java/Kotlin
    • Minimum SDK：最低支持Android版本
    • Use legacy android.support libraries：是否使用旧支持库（推荐不勾选，用AndroidX）

项目结构：

  • app/：应用模块
    • src/main/java/：源码
    • src/main/res/：资源
    • src/main/AndroidManifest.xml：清单文件
    • build.gradle：模块构建配置
  • gradle/：Gradle Wrapper
  • build.gradle：项目构建配置
  • settings.gradle：项目模块配置
  • gradle.properties：Gradle属性

编译运行：

  • 工具栏Run按钮或Shift+F10
  • 选择运行设备（模拟器或真机）
  • Gradle构建APK并安装运行
  • Build菜单：Make Project、Clean Project、Rebuild Project

运行和调试App

模拟器（AVD）：

  • AVD Manager创建虚拟设备
  • 选择设备型号、系统镜像、配置
  • 模拟器启动后可运行App
  • 模拟器支持：旋转屏幕、GPS、网络、电话、短信、摄像头

真机调试：

  • 手机开启开发者选项和USB调试
  • 连接电脑，安装驱动
  • Android Studio识别设备后运行
  • 真机调试比模拟器更接近真实体验

调试（Debug）：

  • 断点：在代码行号左侧点击设置断点
  • Debug模式运行（Shift+F9）
  • 调试窗口：
    • Frames：调用栈
    • Variables：变量值
    • Watches：监视表达式
  • 调试操作：Step Over、Step Into、Step Out、Resume、Stop
  • Logcat：查看应用日志
  • 条件断点、日志断点、异常断点

动手练习

  • 安装Android Studio和SDK
  • 创建第一个Hello World项目
  • 在模拟器和真机上运行
  • 尝试调试，设置断点查看变量

第2章 Android App开发基础

App的开发特点

  • 组件化：四大组件（Activity、Service、BroadcastReceiver、ContentProvider）
  • 声明式UI：XML布局文件定义界面
  • 资源分离：布局、图片、字符串、颜色等资源与代码分离
  • 生命周期：组件有明确的生命周期回调
  • 权限机制：敏感操作需申请权限
  • 多设备适配：不同屏幕尺寸、密度、语言

App的工程结构

详细讲解Android项目各目录和文件的作用：

  • manifests/：AndroidManifest.xml
  • java/：源码（含测试代码）
  • res/：
    • drawable/：图片、形状
    • layout/：布局XML
    • mipmap/：应用图标
    • values/：strings、colors、themes、dimens
    • xml/：XML配置
  • Gradle Scripts/：构建脚本

App的设计规范

Material Design：

  • Google设计语言
  • 材料隐喻、鲜明有意义、动画效果
  • 组件：AppBar、FAB、Card、Snackbar、Dialog、Drawer
  • 颜色：primary、primaryDark、accent
  • 字体：Roboto
  • 图标：Material Icons

屏幕适配：

  • 使用dp/dip作为尺寸单位
  • 使用sp作为字体单位
  • 不同密度提供不同尺寸图片（mdpi/hdpi/xhdpi/xxhdpi）
  • ConstraintLayout灵活适配
  • 最小宽度限定符（sw600dp）适配平板

App的活动页面

Activity概述：

  • Activity是应用的界面，负责用户交互
  • 一个应用通常有多个Activity
  • Activity通过Intent启动和通信

Activity生命周期：

  • onCreate：创建，初始化界面
  • onStart：可见
  • onResume：可交互
  • onPause：暂停
  • onStop：不可见
  • onDestroy：销毁
  • onRestart：重新启动

布局文件：

  • XML定义界面
  • 根布局：ConstraintLayout、LinearLayout等
  • 控件：TextView、Button、ImageView等
  • 属性：id、layout_width、layout_height、text、src等

Activity与布局关联：

  • onCreate中setContentView(R.layout.activity_main)
  • findViewById获取控件引用
  • Kotlin可使用View Binding或Data Binding

动手练习

  • 创建新项目，熟悉工程结构
  • 修改布局，添加TextView和Button
  • 在Activity中获取控件，设置点击事件
  • 观察Activity生命周期回调（日志输出）

第3章 简单控件

文本显示

TextView：

  • 显示文本
  • 常用属性：
    • text：文本内容
    • textSize：字体大小（sp）
    • textColor：字体颜色
    • textStyle：字体样式（bold、italic、normal）
    • gravity：文本对齐方式（center、left、right）
    • maxLines：最大行数
    • ellipsize：省略号位置（end、middle、start）
    • autoLink：自动链接（web、phone、email）
    • drawableLeft/Top/Right/Bottom：文字周围图片

实战项目：

  • 展示不同样式的文本
  • 实现跑马灯效果
  • 实现富文本显示

视图基础

View通用属性：

  • id：控件标识
  • layout_width/layout_height：宽高（match_parent、wrap_content、具体值）
  • layout_margin：外边距
  • padding：内边距
  • background：背景
  • visibility：可见性（visible、invisible、gone）
  • alpha：透明度
  • rotation/rotationX/rotationY：旋转
  • scaleX/scaleY：缩放
  • translationX/translationY：平移

视图层级：

  • View是所有控件基类
  • ViewGroup是容器基类
  • 视图树结构

常用布局

LinearLayout：

  • 线性布局，水平或垂直排列
  • orientation：horizontal/vertical
  • layout_weight：权重分配剩余空间
  • gravity：子元素对齐
  • layout_gravity：自身在父容器中的对齐

RelativeLayout：

  • 相对布局，相对位置排列
  • layout_above/below/toLeftOf/toRightOf
  • layout_alignParentTop/Bottom/Left/Right
  • layout_centerInParent/centerHorizontal/centerVertical
  • 已被ConstraintLayout取代

FrameLayout：

  • 帧布局，层叠排列
  • 子元素按顺序层叠，后加的在上
  • 适用于简单层叠场景

ConstraintLayout：

  • 约束布局，推荐使用
  • 相对约束：layout_constraintLeft_toLeftOf等
  • 比例约束：layout_constraintDimensionRatio
  • 链（Chain）：spread、spread_inside、packed
  • 屏障（Barrier）、Guideline
  • 扁平层级，性能好

TableLayout/GridLayout：

  • 表格/网格布局
  • 适用于表格类界面

按钮触控

Button：

  • 按钮控件
  • text：按钮文字
  • onClick：点击事件（XML中指定方法名）
  • background：按钮背景
  • 点击事件处理：
    • XML中android:onClick
    • setOnClickListener匿名内部类
    • Activity实现OnClickListener接口
    • Lambda表达式（Kotlin/Java 8）

ImageButton：

  • 图片按钮
  • src：图片
  • background：背景

ToggleButton/Switch：

  • 开关按钮
  • checked：是否选中
  • setOnCheckedChangeListener监听状态变化

实战项目：计算器：

  • GridLayout或TableLayout布局
  • 数字按钮和运算符按钮
  • 实现简单计算逻辑
  • 处理连续运算、小数点、清除等

图像显示

ImageView：

  • 显示图片
  • src：图片资源
  • background：背景
  • scaleType：缩放类型
    • fitXY：拉伸填满（变形）
    • fitStart/fitCenter/fitEnd：等比例缩放，对齐
    • center：居中，不缩放
    • centerCrop：等比例缩放填满（裁剪）
    • centerInside：等比例缩放完整显示
  • adjustViewBounds：调整View边界适应图片
  • maxWidth/maxHeight：最大宽高

图片资源：

  • res/drawable/：位图、形状、选择器
  • res/mipmap/：应用图标
  • 不同密度：drawable-mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi
  • WebP格式：更小体积

实战项目：

  • 图片浏览器
  • 图片缩放展示
  • 形状选择器（按下/正常状态）

动手练习

  • 使用各种布局实现界面
  • 实现计算器
  • 实现图片展示
  • 练习按钮点击事件

第4章 常用组件

启停活动页面

Activity启动：

  • 显式Intent：指定目标Activity
  • 隐式Intent：通过Action匹配
  • startActivityForResult：启动并接收返回结果
  • 启动模式：standard、singleTop、singleTask、singleInstance

Activity关闭：

  • finish()：关闭当前Activity
  • 返回键自动关闭
  • setResult设置返回结果

任务栈：

  • Activity按启动顺序入栈
  • 返回键弹出栈顶Activity
  • 启动模式影响任务栈行为

在活动之间传递消息

Intent传递数据：

  • putExtra：存入数据（基本类型、String、Serializable、Parcelable）
  • getXxxExtra：获取数据
  • Bundle：数据容器

接收返回数据：

  • startActivityForResult启动
  • onActivityResult回调接收
  • requestCode：请求码，区分请求
  • resultCode：结果码，RESULT_OK/RESULT_CANCELED
  • data：返回的Intent

传递对象：

  • Serializable：Java序列化，简单但性能差
  • Parcelable：Android序列化，性能好，需实现writeToParcel和CREATOR
  • 大数据避免Intent传递（限制1MB）

收发应用广播

广播概述：

  • 系统/应用间消息传递
  • 标准广播、有序广播、本地广播
  • 静态注册、动态注册

发送广播：

  • sendBroadcast：标准广播
  • sendOrderedBroadcast：有序广播
  • LocalBroadcastManager.sendBroadcast：本地广播
  • Intent指定Action，附加数据

接收广播：

  • 继承BroadcastReceiver
  • 重写onReceive
  • 动态注册：registerReceiver
  • 动态注销：unregisterReceiver
  • 静态注册：AndroidManifest.xml中声明

系统广播：

  • 开机、网络变化、电量变化、屏幕亮灭等
  • 需相应权限

操作后台服务

Service概述：

  • 后台运行，无界面
  • 启动方式：startService、bindService
  • 生命周期：onCreate、onStartCommand、onBind、onUnbind、onDestroy

启动服务：

  • startService启动
  • onStartCommand处理
  • stopService停止
  • 服务独立于启动者

绑定服务：

  • bindService绑定
  • onBind返回IBinder
  • 通过Binder调用服务方法
  • unbindService解绑

前台服务：

  • 显示通知
  • startForeground
  • 不易被系统杀死
  • 适用：音乐播放、下载

IntentService：

  • Service子类
  • 工作线程串行处理
  • 处理完自动停止
  • onHandleIntent处理任务

动手练习

  • 实现Activity跳转和数据传递
  • 实现广播发送和接收
  • 实现Service启动和绑定
  • 实现IntentService后台任务

第6章 数据存储

键值对

SharedPreferences：

  • 轻量级键值存储
  • 存储基本类型：boolean、float、int、long、String
  • getSharedPreferences(name, mode)
  • edit()获取Editor
  • putXxx存入
  • apply()异步提交、commit()同步提交
  • getXxx获取
  • 适用：配置、偏好、小量数据
  • 存储位置：/data/data/<包名>/shared_prefs/

适用场景：

  • 用户偏好设置
  • 登录状态
  • 简单配置
  • 不适合大量数据和结构化数据

数据库

SQLite数据库：

  • 轻量级关系型数据库
  • Android内置
  • 支持SQL语法
  • 事务支持

SQLiteOpenHelper：

  • 继承SQLiteOpenHelper
  • onCreate：创建数据库表
  • onUpgrade：升级数据库
  • getWritableDatabase/getReadableDatabase
  • 构造函数：context、name、factory、version

CRUD操作：

  • insert：插入（ContentValues）
  • delete：删除（where条件）
  • update：更新（ContentValues、where）
  • query：查询（返回Cursor）
  • rawQuery：执行原始SQL
  • execSQL：执行无返回SQL

Cursor：

  • 查询结果集
  • moveToFirst/moveToNext/moveToPosition
  • getXxx获取列值（getColumnIndex获取列索引）
  • close关闭
  • 遍历查询结果

事务：

  • beginTransaction开始
  • setTransactionSuccessful标记成功
  • endTransaction结束
  • 批量操作提升性能

实战项目：购物车：

  • 商品数据库
  • 添加/删除/修改商品
  • 购物车列表展示
  • 数量修改
  • 总价计算

存储卡

内部存储：

  • /data/data/<包名>/files/
  • 仅应用自己可访问
  • openFileInput/openFileOutput
  • 适用：私有文件

外部存储：

  • /sdcard/
  • 所有应用可访问
  • 需权限（WRITE_EXTERNAL_STORAGE）
  • Android 10+分区存储
  • Environment.getExternalStorageDirectory()
  • getExternalFilesDir()：应用专属外部目录

资源文件：

  • res/raw/：原始资源，openRawResource读取
  • assets/：资产文件，AssetManager读取
  • 适用：预置数据、配置文件

文件操作：

  • File、FileInputStream、FileOutputStream
  • BufferedReader、BufferedWriter
  • 目录创建、文件删除

应用组件Application

Application概述：

  • 应用全局单例
  • 应用启动时创建
  • 继承Application
  • onCreate初始化全局配置
  • 通过getApplication()获取

用途：

  • 全局变量
  • 全局初始化（第三方SDK）
  • 全局状态管理
  • 数据共享

共享数据

全局共享方式：

  • Application全局变量

  • SharedPreferences

  • 文件

ContentProvider：

  • 跨应用数据共享
  • URI标识数据
  • ContentResolver操作
  • 系统ContentProvider：联系人、媒体库等

第7章 高级控件

下拉框

第8章 自定义控件

视图的构建过程

View绘制流程：

  • measure：测量尺寸（onMeasure）
  • layout：布局位置（onLayout）
  • draw：绘制（onDraw）
  • 从ViewRootImpl的performTraversals开始

measure：

  • MeasureSpec：32位int，高2位模式（UNSPECIFIED/EXACTLY/AT_MOST），低30位尺寸
  • onMeasure测量，setMeasuredDimension设置
  • 自定义View需重写onMeasure处理wrap_content

layout：

  • layout确定位置，setFrame设置顶点
  • onLayout确定子元素位置（ViewGroup）

draw：

  • 背景 → onDraw → dispatchDraw → 装饰
  • Canvas绘制，Paint画笔

改造已有的控件

继承已有控件：

  • 继承TextView、Button、ImageView等
  • 重写特定方法扩展功能
  • 示例：圆角ImageView、带清除按钮的EditText、计数按钮

自定义属性：

  • res/values/attrs.xml定义declare-styleable
  • 构造函数中TypedArray获取属性值
  • XML中使用app:属性名
  • 属性类型：string、dimension、color、integer、reference、boolean、float、fraction、enum、flag

推送消息通知

Notification：

  • 状态栏通知
  • NotificationCompat.Builder构建
  • 小图标、标题、内容、时间
  • 点击跳转（PendingIntent）
  • 通知渠道（NotificationChannel，Android 8.0+）
    • 重要性、声音、振动、灯光
  • NotificationManager发送
  • 大文本、大图、进度条、按钮等富样式
  • 前台服务必须显示通知

通过持续绘制实现简单动画

自定义绘制动画：

  • 继承View重写onDraw
  • 使用Handler或ValueAnimator驱动重绘
  • invalidate()触发重绘
  • 示例：
    • 圆形进度条
    • 波浪动画
    • 粒子效果
    • 转盘抽奖

Paint和Canvas：

  • Paint：颜色、样式、线宽、抗锯齿、字体
  • Canvas：drawLine/drawRect/drawCircle/drawArc/drawText/drawBitmap/drawPath
  • Path：路径
  • 坐标系、图层、矩阵变换

第10章 打造安装包

应用打包

构建类型：

  • debug：调试版，可调试，未优化
  • release：发布版，优化、混淆、签名
  • build.gradle配置buildTypes

签名配置：

  • 签名文件（.jks/.keystore）
  • keyAlias、keyPassword、storeFile、storePassword
  • release配置signingConfig
  • 签名保证应用身份和完整性

构建APK：

  • Build → Build Bundle(s) / APK(s) → Build APK(s)
  • 或Gradle任务：assembleDebug/assembleRelease
  • 输出位置：app/build/outputs/apk/

规范处理

混淆（ProGuard/R8）：

  • 代码混淆：类名、方法名、字段名重命名
  • 代码压缩：移除未使用代码
  • 资源压缩：shrinkResources移除未使用资源
  • proguard-rules.pro配置混淆规则
  • 保留：实体类、JNI方法、反射使用的类、第三方库规则
  • mapping.txt：混淆映射文件，用于崩溃还原

资源优化：

  • 图片压缩
  • WebP格式转换
  • 移除未使用资源
  • 资源混淆（AndResGuard）
  • 只保留需要的语言和密度

ABI适配：

  • ndk.abiFilters指定支持的ABI
  • armeabi-v7a、arm64-v8a、x86、x86_64
  • 减少APK体积

安全加固

代码安全：

  • 混淆增加逆向难度
  • 字符串加密
  • 加固服务（360加固、腾讯乐固、爱加密）
  • 加壳保护
  • 防调试、防篡改

数据安全：

  • 敏感数据加密存储
  • HTTPS网络传输
  • 证书锁定
  • 密钥安全存储（AndroidKeyStore）

权限最小化：

  • 只申请必要权限
  • 运行时权限
  • targetSdkVersion保持最新

多渠道打包

渠道配置：

  • productFlavors定义渠道
  • 每个渠道可配置不同参数
  • 应用名、包名、图标、渠道号
  • 构建变体 = Build Type + Product Flavor

友盟/多渠道统计：

  • AndroidManifest中meta-data配置渠道号
  • 占位符${CHANNEL}
  • 打包时替换

APK输出命名：

  • build.gradle配置outputFileName
  • 包含应用名、版本、渠道、时间

动手练习

  • 配置签名和混淆
  • 构建release APK
  • 配置多渠道打包
  • 分析APK体积

第11章 事件交互

按键事件

KeyEvent：

  • 按键事件
  • onKeyDown、onKeyUp
  • 按键码：KeyEvent.KEYCODE_XXX
  • 返回键、菜单键、音量键、搜索键
  • 拦截按键事件

返回键处理：

  • onBackPressed
  • 双击返回退出
  • 返回键确认退出对话框

菜单键：

  • onCreateOptionsMenu创建菜单
  • onOptionsItemSelected处理

触摸事件

MotionEvent：

  • 触摸事件
  • 动作：ACTION_DOWN、ACTION_MOVE、ACTION_UP、ACTION_CANCEL
  • 坐标：getX/getY（相对控件）、getRawX/getRawY（相对屏幕）
  • 多指触摸：getPointerId、getActionMasked、ACTION_POINTER_DOWN/UP

onTouchEvent：

  • View的触摸事件回调
  • 返回true表示消费事件
  • 处理按下、移动、抬起

OnTouchListener：

  • setOnTouchListener设置触摸监听
  • onTouch回调
  • 优先级高于onTouchEvent

根据触摸行为辨别手势动作

手势检测：

  • GestureDetector
  • OnGestureListener：
    • onDown：按下
    • onShowPress：按下未移动未抬起
    • onSingleTapUp：单击抬起
    • onScroll：滚动
    • onLongPress：长按
    • onFling：快速滑动（抛掷）
  • OnDoubleTapListener：
    • onSingleTapConfirmed：单击确认
    • onDoubleTap：双击
    • onDoubleTapEvent：双击事件

ScaleGestureDetector：

  • 缩放手势检测
  • onScaleBegin、onScale、onScaleEnd
  • 缩放因子getScaleFactor

自定义手势：

  • 记录按下位置、移动距离、速度
  • 判断滑动方向
  • 判断点击、长按、滑动
  • VelocityTracker计算速度

手势冲突处理

事件分发机制：

  • dispatchTouchEvent：分发事件
  • onInterceptTouchEvent：拦截事件（ViewGroup）
  • onTouchEvent：处理事件
  • 传递顺序：Activity → Window → DecorView → ViewGroup → View
  • 返回true消费事件

滑动冲突：

  • 场景：ScrollView嵌套ListView、ViewPager嵌套ScrollView
  • 外部拦截法：父容器onInterceptTouchEvent处理
    • DOWN不拦截
    • MOVE按需拦截（判断滑动方向）
    • UP不拦截
  • 内部拦截法：子元素requestDisallowInterceptTouchEvent配合
  • 解决滑动冲突，提升用户体验

实战项目：仿美图秀秀的抠图工具

  • 图片显示
  • 手指绘制抠图区域
  • 手势缩放/移动图片
  • 抠图效果
  • 保存图片

第12章 动画特效

补间动画

Tween Animation：

  • 对View进行变换
  • 类型：
    • AlphaAnimation：透明度
    • ScaleAnimation：缩放
    • TranslateAnimation：位移
    • RotateAnimation：旋转
    • AnimationSet：集合
  • XML定义（res/anim/）或代码创建
  • 插值器Interpolator控制变化速率
  • startAnimation启动
  • 缺点：只改变显示，不改变实际位置

常用插值器：

  • AccelerateInterpolator：加速
  • DecelerateInterpolator：减速
  • AccelerateDecelerateInterpolator：先加速后减速
  • LinearInterpolator：匀速
  • BounceInterpolator：弹跳
  • OvershootInterpolator：超出回弹
  • AnticipateInterpolator：先回退再前进
  • CycleInterpolator：循环

帧动画

Frame Animation：

  • 一系列图片依次播放
  • AnimationDrawable
  • XML定义（res/drawable/）：animation-list
  • item：drawable、duration
  • start/stop播放
  • 适用：加载动画、简单特效

属性动画

Property Animation：

  • Android 3.0+引入
  • 真正改变对象属性
  • 核心类：
    • ValueAnimator：值动画
    • ObjectAnimator：对象动画
    • AnimatorSet：动画集合
    • Keyframe：关键帧
    • TypeEvaluator：估值器

ObjectAnimator：

  • ofFloat、ofInt、ofArgb
  • 属性名：alpha、translationX、scaleX、rotation、x、y
  • 自动更新属性
  • 链式调用

ValueAnimator：

  • 只计算值变化
  • addUpdateListener监听值变化，手动更新
  • 适用于自定义属性

AnimatorSet：

  • playSequentially顺序播放
  • playTogether同时播放
  • play().with().before().after()

XML定义：

  • res/animator/
  • animator、objectAnimator、set

布局动画：

  • LayoutTransition
  • ViewGroup布局变化时的动画
  • 出现、消失、变化动画

转场动画：

  • Transition框架（Android 4.4+）
  • Activity转场：explode、slide、fade
  • 共享元素转场（Shared Element）
  • Scene场景切换

实战项目
