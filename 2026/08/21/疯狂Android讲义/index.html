疯狂Android讲义

疯狂Android讲义（第四版）

作者：李刚
全书共约20章，768页，Android开发入门到进阶的经典教材，内容全面，涵盖Android应用开发的方方面面，配有大量实战案例。

第1章 Android应用开发基础

Android简介

Android是基于Linux内核的开源移动操作系统，由Google主导开发。

  • 应用层：Java/Kotlin编写的应用
  • 应用框架层：Java API
  • 系统运行库层：C/C++库 + ART
  • HAL：硬件抽象层
  • Linux内核：驱动、进程管理、内存管理

开发环境搭建

  • JDK安装配置
  • Android Studio安装
  • SDK下载配置
  • AVD（Android虚拟设备）创建
  • 真机调试配置（USB调试、驱动）

第一个Android应用

  • 创建项目：选择模板、配置包名、最低SDK版本
  • 项目结构：
    • app/src/main/java/：Java/Kotlin源码
    • app/src/main/res/：资源文件（layout、drawable、values等）
    • app/src/main/AndroidManifest.xml：清单文件
    • build.gradle：构建配置
  • 运行应用：模拟器或真机
  • 应用打包：生成APK

Android应用结构

  • Activity：界面，用户交互
  • Service：后台服务，无界面
  • BroadcastReceiver：广播接收者
  • ContentProvider：数据共享
  • 清单文件：声明组件、权限、SDK版本
  • 资源：布局、字符串、图片、颜色、尺寸

第2章 Android应用界面编程

View与ViewGroup

  • View是所有UI控件的基类
  • ViewGroup是控件容器，继承自View
  • View树：DecorView为根

常用布局

  • LinearLayout：线性布局，水平或垂直排列
    • orientation：horizontal/vertical
    • layout_weight：权重分配
  • RelativeLayout：相对布局，相对位置排列
    • layout_above、layout_below、layout_toLeftOf等
  • FrameLayout：帧布局，层叠排列
  • TableLayout：表格布局
  • GridLayout：网格布局
  • ConstraintLayout：约束布局，灵活强大，推荐使用
    • 相对约束、链、屏障、Guideline

常用控件

  • TextView：文本显示
    • text、textSize、textColor、textStyle、gravity
  • EditText：文本输入
    • inputType、hint、maxLength、imeOptions
  • Button：按钮
    • onClick事件
  • ImageView：图片显示
    • src、scaleType（fitXY、centerCrop、fitCenter等）
  • CheckBox/RadioButton：复选框/单选按钮
    • RadioGroup管理单选
  • Spinner：下拉选择
  • ProgressBar：进度条
  • SeekBar：拖动条
  • Switch/ToggleButton：开关
  • ListView/GridView：列表/网格视图
  • RecyclerView：高级列表（推荐）

事件处理

  • 基于监听的事件处理：
    • OnClickListener、OnLongClickListener、OnTouchListener、OnFocusChangeListener、OnKeyListener
    • 实现方式：匿名内部类、内部类、Activity实现接口、布局XML中onClick属性
  • 基于回调的事件处理：
    • 重写View的回调方法：onKeyDown、onTouchEvent、onTrackballEvent
    • 事件传播顺序：监听器优先，然后回调方法
  • Handler消息传递：
    • Handler.sendMessage、post
    • Looper、MessageQueue
    • 子线程更新UI

对话框

  • AlertDialog：警告对话框
    • 标题、消息、按钮（确定/取消/中性）
    • 列表对话框、单选/多选对话框
    • 自定义布局对话框
  • ProgressDialog：进度对话框
  • DatePickerDialog/TimePickerDialog：日期/时间选择对话框
  • PopupWindow：弹出窗口
  • Toast：短暂提示
  • Snackbar：底部提示（Material Design）

菜单

  • 选项菜单（Options Menu）：
    • onCreateOptionsMenu创建
    • onOptionsItemSelected处理
    • XML定义菜单（res/menu/）
  • 上下文菜单（Context Menu）：
    • 长按触发
    • onCreateContextMenu、onContextItemSelected
    • registerForContextMenu注册
  • 弹出菜单（PopupMenu）：
    • 锚定到View的弹出菜单

第3章 Activity与Intent

Activity概述

Activity是Android应用的界面组件，负责用户交互。

  • 每个Activity是一个界面
  • 应用通常由多个Activity组成
  • Activity间通过Intent通信

Activity生命周期

  • onCreate：创建，初始化
  • onStart：可见，但不可交互
  • onResume：可见且可交互（运行态）
  • onPause：暂停，部分可见，不可交互
  • onStop：停止，不可见
  • onDestroy：销毁
  • onRestart：重新启动（从停止态恢复）

生命周期转换：

  • 启动：onCreate → onStart → onResume
  • 按Home：onPause → onStop
  • 回到应用：onRestart → onStart → onResume
  • 按返回：onPause → onStop → onDestroy
  • 横竖屏切换：onPause → onStop → onDestroy → onCreate → onStart → onResume

Activity启动模式

  • standard：标准模式，每次启动创建新实例
  • singleTop：栈顶复用，若目标Activity在栈顶则复用，否则创建新实例
  • singleTask：栈内复用，若目标Activity在栈内则复用并清除其上所有Activity，否则创建新实例
  • singleInstance：单实例，独占一个任务栈

Intent

Intent是组件间通信的消息对象。

  • 显式Intent：指定组件名，用于应用内跳转
  • 隐式Intent：通过Action、Category、Data匹配，用于跨应用调用
  • Intent属性：
    • Component：目标组件
    • Action：动作（ACTION_VIEW、ACTION_CALL等）
    • Category：类别
    • Data：数据（URI + MIME类型）
    • Extras：附加数据（Bundle）
    • Flags：标志

Activity间数据传递

  • Intent传递数据：
    • putExtra：基本类型、String、Serializable、Parcelable
    • getXxxExtra：获取数据
  • Bundle：数据容器，可放入Intent
  • startActivityForResult：
    • 启动Activity并接收返回结果
    • onActivityResult回调
    • setResult设置结果
  • 大数据传递：避免Intent传递大数据（限制1MB），用静态变量、文件、数据库

第4章 数据存储

SharedPreferences

  • 轻量级存储，键值对形式
  • 存储基本类型：boolean、float、int、long、String
  • 存储位置：/data/data/<包名>/shared_prefs/
  • 使用：
    • getSharedPreferences(name, mode)获取实例
    • edit()获取Editor
    • putXxx存入数据
    • apply()/commit()提交
  • 适用：配置信息、用户偏好、小量数据

文件存储

  • 内部存储：
    • /data/data/<包名>/files/
    • 仅应用自己可访问
    • openFileInput/openFileOutput
  • 外部存储：
    • /sdcard/
    • 所有应用可访问，需权限
    • Environment.getExternalStorageDirectory()
    • Android 10+分区存储（Scoped Storage）
  • 资源文件：
    • res/raw/：原始资源，通过openRawResource读取
    • assets/：资产文件，通过AssetManager读取
  • 文件操作：FileInputStream、FileOutputStream、BufferedReader、BufferedWriter

SQLite数据库

  • 轻量级关系型数据库，嵌入式
  • Android内置SQLite
  • SQLiteOpenHelper：
    • 继承SQLiteOpenHelper
    • onCreate：创建数据库
    • onUpgrade：升级数据库
    • getWritableDatabase/getReadableDatabase获取数据库实例
  • CRUD操作：
    • insert：插入
    • delete：删除
    • update：更新
    • query：查询，返回Cursor
  • Cursor：查询结果集，moveToFirst/moveToNext/getXxx遍历
  • 事务：
    • beginTransaction开始
    • setTransactionSuccessful标记成功
    • endTransaction结束
  • 适用：结构化数据、大量数据、需查询/排序

ContentProvider

  • 跨应用数据共享
  • 通过URI标识数据
  • ContentResolver操作ContentProvider
  • 系统ContentProvider：联系人、短信、媒体库、日历等
  • 自定义ContentProvider：
    • 继承ContentProvider
    • 实现onCreate、query、insert、update、delete、getType
    • UriMatcher匹配URI
  • 适用：跨应用数据共享

第5章 广播接收者

BroadcastReceiver概述

  • 广播接收者，监听系统/应用广播
  • 系统广播：开机完成、网络变化、电量变化、短信、电话等
  • 应用广播：应用内/跨应用自定义广播

广播类型

  • 标准广播（Normal Broadcast）：
    • 异步，所有接收者同时接收
    • 不可截断
  • 有序广播（Ordered Broadcast）：
    • 同步，按优先级顺序接收
    • 可截断（abortBroadcast）
    • 可传递数据（setResultData）
  • 本地广播（Local Broadcast）：
    • 应用内广播，不跨应用
    • LocalBroadcastManager管理
    • 更安全高效
  • 粘性广播（Sticky Broadcast）：
    • 广播后保留，新注册的接收者也能收到
    • 已废弃（API 21+）

注册方式

  • 静态注册：
    • AndroidManifest.xml中声明
    • 应用未启动也能接收（部分系统广播）
    • Android 8.0+对静态注册隐式广播有限制
  • 动态注册：
    • registerReceiver注册
    • unregisterReceiver注销
    • 必须在组件生命周期内注册注销
    • 更灵活，推荐使用

发送广播

  • sendBroadcast：发送标准广播
  • sendOrderedBroadcast：发送有序广播
  • LocalBroadcastManager.sendBroadcast：发送本地广播
  • Intent指定Action，可附加数据

常用系统广播

  • ACTION_BOOT_COMPLETED：开机完成
  • ACTION_CONNECTIVITY_CHANGE：网络变化
  • ACTION_BATTERY_CHANGED：电量变化
  • ACTION_POWER_CONNECTED/DISCONNECTED：充电/断电
  • ACTION_SCREEN_ON/OFF：亮屏/灭屏
  • ACTION_PACKAGE_ADDED/REMOVED：应用安装/卸载
  • SMS_RECEIVED：接收短信（需权限）

第6章 服务

Service概述

Service是Android的后台服务组件，无界面，在后台运行。

  • 长期运行的后台任务
  • 不与用户交互
  • 运行在主线程（耗时操作需开子线程）

Service生命周期

  • onCreate：创建
  • onStartCommand：启动服务（startService方式）
  • onBind：绑定服务（bindService方式）
  • onUnbind：解绑
  • onDestroy：销毁

启动方式

  • startService：
    • 启动服务，服务独立于启动者
    • 调用onStartCommand
    • stopService停止
    • 服务可在后台长期运行
  • bindService：
    • 绑定服务，服务与绑定者关联
    • 调用onBind，返回IBinder
    • unbindService解绑
    • 所有绑定者解绑后服务销毁
    • 可与服务交互（调用服务方法）
  • 可同时使用两种方式

Service分类

  • 前台服务（Foreground Service）：
    • 显示通知，优先级高
    • 不易被系统杀死
    • startForeground启动
    • 适用：音乐播放、下载、导航
  • 后台服务（Background Service）：
    • 无通知，优先级低
    • 系统内存不足时可能被杀死
    • Android 8.0+后台服务限制
  • 绑定服务（Bound Service）：
    • 通过bindService绑定
    • 客户端-服务端模式
    • 可调用服务方法

IntentService

  • Service的子类，处理异步请求
  • 内部有工作线程，串行处理请求
  • 处理完所有请求后自动停止
  • onHandleIntent处理具体任务
  • 适用：串行异步任务，处理完自动停止

服务通信

  • Binder：
    • 绑定服务时返回IBinder
    • 客户端通过Binder调用服务方法
    • 适用：应用内服务通信
  • Messenger：
    • 基于Handler的消息通信
    • 支持跨进程
    • 串行处理消息
  • AIDL：
    • Android接口定义语言
    • 跨进程通信
    • 支持并发
    • 适用：复杂跨进程服务

第7章 内容提供者

ContentProvider概述

ContentProvider是Android的数据共享组件，用于跨应用共享数据。

  • 统一数据访问接口
  • 底层数据可由SQLite、文件、网络等实现
  • 通过URI标识数据

URI

  • 格式：content://<authority>/<path>/<id>
    • scheme：content://
    • authority：授权者，标识ContentProvider
    • path：路径，标识数据类型
    • id：可选，标识具体记录
  • 示例：content://com.example.provider/books/1
  • ContentUris工具类：withAppendedId、parseId

ContentResolver

  • 通过ContentResolver操作ContentProvider
  • getContentResolver()获取实例
  • 方法：
    • query：查询
    • insert：插入
    • update：更新
    • delete：删除
    • getType：获取MIME类型

自定义ContentProvider

  1. 继承ContentProvider
  2. 实现6个方法：
    • onCreate：初始化
    • query：查询
    • insert：插入
    • update：更新
    • delete：删除
    • getType：返回MIME类型
  3. AndroidManifest.xml中声明：
    • android:authorities
    • android:exported
    • android:permission（可选）
  4. UriMatcher：匹配URI，返回自定义代码
  5. ContentUris：解析ID、追加ID

系统ContentProvider

  • 联系人：ContactsContract
  • 短信：Telephony.Sms
  • 通话记录：CallLog
  • 媒体库：MediaStore（图片、视频、音频）
  • 日历：CalendarContract
  • 书签：Browser
  • 访问需相应权限

ContentObserver

  • 监听ContentProvider数据变化
  • 注册：getContentResolver().registerContentObserver(uri, notifyForDescendents, observer)
  • onChange回调
  • 适用：监听数据变化，自动更新UI

第8章 资源与国际化

Android资源

资源是应用中不包含在代码中的外部文件，如布局、图片、字符串等。

  • 存储在res/目录下
  • 通过R类引用
  • 编译时处理

资源类型

  • layout：布局XML
  • drawable：图片、形状、选择器
  • mipmap：应用图标（不同密度）
  • values：字符串、颜色、尺寸、样式、主题
  • raw：原始资源文件
  • xml：XML配置文件
  • anim：补间动画
  • animator：属性动画
  • menu：菜单
  • font：字体

资源引用

  • Java代码：R.string.app_name、R.layout.activity_main、R.drawable.icon
  • XML：@string/app_name、@layout/activity_main、@drawable/icon
  • 系统资源：@android:string/ok、android.R.string.ok

资源适配

  • 资源目录可加限定符，系统根据设备配置选择
  • 限定符：
    • 语言区域：values-zh、values-zh-rCN
    • 屏幕密度：drawable-mdpi、drawable-hdpi、drawable-xhdpi、drawable-xxhdpi
    • 屏幕方向：layout-land、layout-port
    • 屏幕尺寸：layout-large、layout-xlarge
    • 最小宽度：values-sw600dp
    • 夜间模式：values-night
    • 平台版本：values-v21

国际化（i18n）

  • 多语言支持：
    • values/strings.xml（默认）
    • values-zh/strings.xml（中文）
    • values-en/strings.xml（英文）
    • values-ja/strings.xml（日文）
  • 字符串资源引用，不硬编码
  • 系统根据设备语言自动选择
  • 格式化字符串：%1$s、%2$d，String.format
  • 复数资源：plurals（one/other等）

尺寸与单位

  • dp/dip：设备无关像素，推荐用于布局尺寸
  • sp：缩放无关像素，推荐用于字体大小
  • px：像素，不推荐（不同密度显示不同）
  • pt：磅，1/72英寸
  • in：英寸
  • mm：毫米
  • dp与px转换：px = dp * (dpi / 160)
  • 不同密度：mdpi(160)、hdpi(240)、xhdpi(320)、xxhdpi(480)、xxxhdpi(640)

主题与样式

  • 样式（Style）：一组属性集合，可应用于控件
    • 定义在res/values/styles.xml
    • parent继承样式
    • 通过style属性应用
  • 主题（Theme）：应用于Activity/Application的样式
    • 通过android:theme属性
    • 影响整个界面外观
    • Material Design主题：Theme.Material.Light、Theme.AppCompat.Light等
  • 自定义主题颜色：colorPrimary、colorPrimaryDark、colorAccent

第9章 图形与动画

2D图形

  • Drawable：可绘制对象的抽象
    • BitmapDrawable：位图
    • ShapeDrawable：形状（矩形、椭圆、线、环）
    • StateListDrawable：状态选择器
    • LayerDrawable：图层叠加
    • TransitionDrawable：过渡
  • Canvas绘图：
    • 自定义View重写onDraw
    • Canvas：画布，drawLine/drawRect/drawCircle/drawText/drawBitmap
    • Paint：画笔，颜色、粗细、样式、抗锯齿
    • Path：路径
    • 坐标系：左上角为原点，x向右，y向下
  • Bitmap：
    • BitmapFactory解码图片
    • Bitmap.createBitmap创建
    • 图片压缩：inSampleSize采样
    • 内存管理：recycle回收
    • 三级缓存：内存缓存、磁盘缓存、网络

动画

补间动画（Tween Animation）：

  • 对View进行变换
  • 类型：
    • AlphaAnimation：透明度
    • ScaleAnimation：缩放
    • TranslateAnimation：位移
    • RotateAnimation：旋转
    • AnimationSet：动画集合
  • XML定义（res/anim/）或代码创建
  • 插值器（Interpolator）：控制动画变化速率
    • AccelerateInterpolator、DecelerateInterpolator、AccelerateDecelerateInterpolator、BounceInterpolator、OvershootInterpolator
  • 缺点：只改变显示，不改变实际位置（点击区域不变）

帧动画（Frame Animation）：

  • 一系列图片依次播放
  • AnimationDrawable
  • XML定义（res/drawable/）：animation-list
  • 适用：简单动画、加载动画

属性动画（Property Animation）：

  • Android 3.0+引入
  • 可对任意对象的属性进行动画
  • 真正改变属性值
  • 核心类：
    • ValueAnimator：值动画，监听值变化手动更新
    • ObjectAnimator：对象动画，直接更新对象属性
    • AnimatorSet：动画集合
  • XML定义（res/animator/）
  • 常用属性：alpha、translationX/Y、scaleX/Y、rotation、x/y
  • 估值器（TypeEvaluator）：计算属性值（IntEvaluator、FloatEvaluator、ArgbEvaluator）
  • 关键帧（Keyframe）：多段动画

自定义View

  • 继承View或ViewGroup
  • 重写onMeasure：测量尺寸
  • 重写onLayout：布局子元素（ViewGroup）
  • 重写onDraw：绘制
  • 自定义属性：
    • res/values/attrs.xml定义declare-styleable
    • 构造函数中TypedArray获取属性值
    • XML中使用app:属性名
  • 事件处理：onTouchEvent、onInterceptTouchEvent
  • 性能优化：
    • 避免在onDraw中创建对象
    • 使用clipRect减少绘制区域
    • 硬件加速

第10章 多媒体

音频播放

  • MediaPlayer：
    • 播放音频/视频
    • 状态机：Idle → Initialized → Prepared → Started → Paused → Stopped → PlaybackCompleted → End
    • 方法：setDataSource、prepare/prepareAsync、start、pause、stop、release
    • 监听：OnPreparedListener、OnCompletionListener、OnErrorListener
    • 播放来源：本地文件、资源(res/raw)、网络URL
  • SoundPool：
    • 播放短音效，支持同时播放多个
    • 适用：游戏音效、提示音
    • load加载、play播放、release释放
  • AudioManager：
    • 音频管理：音量、铃声模式、音频焦点
    • 音频焦点：requestAudioFocus、abandonAudioFocus
  • AudioTrack：
    • 底层音频播放，播放PCM数据
    • 适用：音频处理、流式播放

视频播放

  • VideoView：
    • 简单视频播放控件
    • 继承SurfaceView
    • setVideoPath/setVideoURI、start、pause、seekTo
    • MediaController：播放控制条
  • MediaPlayer + SurfaceView：
    • 更灵活的视频播放
    • MediaPlayer.setDisplay(surfaceHolder)
  • ExoPlayer：
    • Google开源播放器
    • 支持更多格式、自适应码率、DRM
    • 推荐使用

音频录制

  • MediaRecorder：
    • 录制音频/视频
    • 状态机
    • 方法：setAudioSource、setOutputFormat、setAudioEncoder、setOutputFile、prepare、start、stop、release
    • 权限：RECORD_AUDIO
  • AudioRecord：
    • 底层音频录制，获取PCM数据
    • 适用：音频处理、实时处理

相机

  • Camera API（已废弃）：
    • Camera类

    • 权限：CAMERA
  • Camera2 API：
    • Android 5.0+新相机API
    • CameraManager、CameraDevice、CameraCaptureSession、CaptureRequest
    • 更强大灵活
  • 相机意图：
    • MediaStore.ACTION_IMAGE_CAPTURE
    • 调用系统相机，无需相机权限
    • onActivityResult获取照片

相册与图片

  • 选择图片：
    • Intent.ACTION_PICK / ACTION_GET_CONTENT
    • 调用系统相册
  • 拍照：
    • 相机意图
    • FileProvider共享文件
  • 图片处理：
    • BitmapFactory解码
    • Matrix变换（缩放、旋转、平移）
    • 图片压缩
    • 圆角、裁剪

第11章 网络编程

HTTP网络请求

  • HttpURLConnection：
    • Java标准HTTP客户端
    • URL.openConnection获取
    • setRequestMethod、setDoOutput、getInputStream
    • 简单轻量
  • OkHttp：
    • Square开源HTTP客户端
    • 高效、支持连接池、GZIP、缓存、SPDY/HTTP2
    • 同步/异步请求
    • Request、Response、Call、OkHttpClient
  • Retrofit：
    • Square开源REST客户端
    • 基于OkHttp
    • 注解定义API接口
    • 自动解析JSON（Gson/Jackson）
    • 支持RxJava
  • Volley：
    • Google开源网络库
    • 适合小数据高频请求
    • RequestQueue、StringRequest、JsonObjectRequest、ImageRequest
    • 不适合大文件下载/上传

JSON解析

  • org.json：
    • Android内置JSON解析
    • JSONObject、JSONArray
    • 简单但手动解析繁琐
  • Gson：
    • Google开源JSON库

  • Jackson：
    • 高性能JSON库
    • ObjectMapper
    • 注解：@JsonProperty、@JsonIgnore
  • Fastjson：
    • 阿里巴巴开源JSON库
    • 高性能
    • JSON.parseObject、JSON.toJSONString

WebSocket

  • 全双工通信，长连接
  • 适用：即时通信、实时数据推送
  • 库：OkHttp WebSocket、Java-WebSocket、Scarlet
  • 生命周期：connect、onOpen、onMessage、onClose、onError

下载与上传

  • 下载：
    • HttpURLConnection/OkHttp获取InputStream
    • 写入文件
    • 进度监听
    • 断点续传：Range请求头
  • 上传：
    • multipart/form-data
    • OkHttp MultipartBody
    • 进度监听

网络安全

  • HTTPS：
    • 加密传输
    • 证书验证
    • 自定义TrustManager
    • 证书锁定（Certificate Pinning）
  • 网络安全配置：
    • res/xml/network_security_config.xml
    • 允许/禁止明文流量

  • 数据加密：
    • AES加密敏感数据
    • RSA加密密钥
    • AndroidKeyStore安全存储密钥

第12章 传感器

传感器概述

Android支持多种传感器，用于感知设备环境和运动。

  • 硬件传感器：加速度、陀螺仪、磁力计、光线、距离、气压、温度、湿度、心率
  • 软件传感器：方向、重力、线性加速度、旋转矢量（由硬件传感器融合计算）

SensorManager

  • 获取传感器服务：getSystemService(SENSOR_SERVICE)
  • getDefaultSensor(type)获取默认传感器
  • getSensorList(type)获取所有传感器
  • registerListener注册监听
  • unregisterListener注销监听
  • 传感器类型常量：
    • TYPE_ACCELEROMETER：加速度
    • TYPE_GYROSCOPE：陀螺仪
    • TYPE_MAGNETIC_FIELD：磁力计
    • TYPE_LIGHT：光线
    • TYPE_PROXIMITY：距离
    • TYPE_PRESSURE：气压
    • TYPE_ORIENTATION：方向（已废弃）
    • TYPE_GRAVITY：重力
    • TYPE_LINEAR_ACCELERATION：线性加速度
    • TYPE_ROTATION_VECTOR：旋转矢量
    • TYPE_STEP_COUNTER/STEP_DETECTOR：计步

SensorEventListener

  • onSensorChanged(SensorEvent event)：传感器数据变化
    • event.values：传感器数据数组（不同传感器含义不同）
    • event.accuracy：精度
    • event.timestamp：时间戳
  • onAccuracyChanged(Sensor sensor, int accuracy)：精度变化

采样频率

  • SENSOR_DELAY_FASTEST：最快（约0ms）
  • SENSOR_DELAY_GAME：游戏（约20ms）
  • SENSOR_DELAY_UI：UI（约60ms）
  • SENSOR_DELAY_NORMAL：正常（约200ms）
  • 或指定延迟微秒数

常用传感器

加速度传感器：

  • values[0]：x轴加速度
  • values[1]：y轴加速度
  • values[2]：z轴加速度
  • 单位：m/s²
  • 包含重力加速度
  • 应用：摇一摇、运动检测、屏幕旋转

陀螺仪：

  • values[0]：x轴角速度
  • values[1]：y轴角速度
  • values[2]：z轴角速度
  • 单位：rad/s
  • 应用：游戏视角、姿态跟踪、VR

磁力计：

  • values[0]：x轴磁场
  • values[1]：y轴磁场
  • values[2]：z轴磁场
  • 单位：μT
  • 应用：指南针、方向检测

光线传感器：

  • values[0]：光照强度
  • 单位：lux
  • 应用：自动亮度调节

距离传感器：

  • values[0]：距离
  • 单位：cm
  • 应用：通话时灭屏

方向传感器（软件）：

  • values[0]：方位角（0=北，90=东，180=南，270=西）
  • values[1]：俯仰角
  • values[2]：翻滚角
  • 由加速度+磁力计计算
  • 推荐用旋转矢量传感器替代

传感器融合

  • 单一传感器有局限（加速度有重力、陀螺仪漂移、磁力计受干扰）
  • 传感器融合结合多个传感器数据，获得更准确稳定的结果
  • 旋转矢量传感器（TYPE_ROTATION_VECTOR）是传感器融合的结果
  • 应用：AR、VR、姿态跟踪、导航

第13章 定位与地图

定位服务

Android提供多种定位方式：

  • GPS定位：
    • 精度高（10-100米）
    • 耗电多
    • 室内不可用
    • 需权限：ACCESS_FINE_LOCATION
  • 网络定位：
    • 基于WiFi/基站
    • 精度低（100-1000米）
    • 耗电少
    • 室内可用
    • 需权限：ACCESS_COARSE_LOCATION
  • 被动定位：
    • 接收其他应用的定位更新
    • 省电
    • 需权限：ACCESS_FINE_LOCATION

LocationManager

  • 获取定位服务：getSystemService(LOCATION_SERVICE)
  • 定位提供者：
    • GPS_PROVIDER：GPS
    • NETWORK_PROVIDER：网络
    • PASSIVE_PROVIDER：被动
  • requestLocationUpdates请求定位更新
  • getLastKnownLocation获取最后已知位置
  • LocationListener监听：
    • onLocationChanged：位置变化
    • onStatusChanged：状态变化
    • onProviderEnabled/Disabled：提供者启用/禁用
  • Criteria：选择最佳提供者（精度、功耗、海拔、速度、方向）

权限处理

  • Android 6.0+运行时权限
  • 定位权限：
    • ACCESS_FINE_LOCATION：精确定位
    • ACCESS_COARSE_LOCATION：粗略定位
    • ACCESS_BACKGROUND_LOCATION：后台定位（Android 10+）
  • 检查权限、请求权限、处理结果

高德/百度地图SDK

  • 国内地图服务常用高德或百度地图SDK
  • 功能：
    • 地图显示
    • 定位
    • 标记（Marker）
    • 信息窗口（InfoWindow）
    • 路径规划（驾车、步行、公交、骑行）
    • 地理编码/逆地理编码
    • POI搜索
    • 导航
  • 使用步骤：
    1. 申请API Key
    2. 导入SDK
    3. 配置权限和Key
    4. MapView显示地图
    5. AMap操作地图

地理编码

  • 地理编码：地址 → 经纬度
  • 逆地理编码：经纬度 → 地址
  • Geocoder类（Android内置，国内可能不可用）
  • 高德/百度地图SDK提供地理编码服务

第14章 蓝牙与WiFi

蓝牙

蓝牙概述：

  • 短距离无线通信技术
  • 经典蓝牙（BT）：音频、文件传输
  • 低功耗蓝牙（BLE）：物联网、可穿戴设备，低功耗

经典蓝牙：

  • BluetoothAdapter：蓝牙适配器
    • getDefaultAdapter获取
    • isEnabled检查是否启用
    • enable/disable启用/禁用
    • startDiscovery开始搜索
    • getBondedDevices获取已配对设备
  • BluetoothDevice：蓝牙设备
    • getName、getAddress
    • createBond配对
    • createRfcommSocketToServiceRecord创建连接
  • BluetoothSocket：蓝牙套接字
    • connect连接
    • getInputStream/getOutputStream
  • BluetoothServerSocket：服务端套接字
    • listenUsingRfcommWithServiceRecord
    • accept接受连接
  • 权限：BLUETOOTH、BLUETOOTH_ADMIN、ACCESS_FINE_LOCATION（Android 6.0+搜索需位置权限）

低功耗蓝牙（BLE）：

  • BluetoothLeScanner：扫描BLE设备
  • BluetoothGatt：GATT客户端
  • BluetoothGattService：GATT服务
  • BluetoothGattCharacteristic：特征值
  • BluetoothGattDescriptor：描述符
  • 流程：扫描 → 连接 → 发现服务 → 读写特征值 → 通知
  • 适用：心率带、血压计、智能手环、智能家居

WiFi

WiFi概述：

  • 无线局域网技术
  • WiFi管理：扫描、连接、配置

WifiManager：

  • 获取WiFi服务：getSystemService(WIFI_SERVICE)
  • isWifiEnabled检查是否启用
  • setWifiEnabled启用/禁用
  • startScan开始扫描
  • getScanResults获取扫描结果（ScanResult：SSID、BSSID、信号强度、加密方式）
  • getConnectionInfo获取当前连接信息（WifiInfo：SSID、BSSID、IP地址、信号强度）
  • getConfiguredNetworks获取已配置网络
  • addNetwork/removeNetwork添加/删除网络配置
  • enableNetwork连接网络
  • 权限：ACCESS_WIFI_STATE、CHANGE_WIFI_STATE、ACCESS_FINE_LOCATION（Android 6.0+扫描需位置权限）

WiFi直连（Wi-Fi Direct）：

  • 设备间直接WiFi连接，无需热点
  • WifiP2pManager管理
  • 适用：文件传输、屏幕共享

热点（Tethering）：

  • 手机作为WiFi热点
  • ConnectivityManager管理
  • 需权限：CHANGE_NETWORK_STATE

第15章 NDK开发

NDK概述

NDK（Native Development Kit）允许在Android应用中使用C/C++代码。

  • 适用场景：
    • 性能关键代码（游戏引擎、音视频编解码、图像处理）
    • 复用C/C++库
    • 安全敏感代码（加密算法，增加逆向难度）
  • 不推荐：普通业务逻辑（Java/Kotlin更简单高效）

NDK开发环境

  • Android Studio安装NDK、CMake、LLDB
  • CMake构建工具（推荐）
  • ndk-build（旧方式）

JNI

JNI（Java Native Interface）是Java与C/C++交互的桥梁。

  • Java声明native方法
  • C/C++实现native方法
  • 方法命名规则：Java_包名_类名_方法名
  • 数据类型映射：
    • Java基本类型 ↔ C基本类型（jint、jlong、jfloat等）
    • Java对象 ↔ jobject、jstring、jarray等
  • JNIEnv：JNI环境指针，提供大量函数
    • 字符串操作：GetStringUTFChars、ReleaseStringUTFChars、NewStringUTF
    • 数组操作：GetIntArrayElements、ReleaseIntArrayElements、NewIntArray
    • 对象操作：GetFieldID、GetObjectField、CallObjectMethod
    • 异常处理：ThrowNew、ExceptionCheck、ExceptionClear

CMake配置

  • CMakeLists.txt：
  • build.gradle配置externalNativeBuild
  • 生成.so库（不同ABI：armeabi-v7a、arm64-v8a、x86、x86_64）

NDK调试

  • LLDB调试C/C++代码
  • 断点、单步、变量查看
  • log输出：__android_log_print

常见NDK库

  • OpenSL ES：底层音频
  • OpenGL ES：图形渲染
  • OpenCV：计算机视觉
  • FFmpeg：音视频处理
  • libpng、libjpeg：图片处理

第16章 性能优化

性能优化概述

Android性能优化目标：

  • 流畅：界面不卡顿，60fps
  • 稳定：无崩溃、无ANR
  • 省电：减少电量消耗
  • 省流量：减少网络流量
  • 省内存：减少内存占用

UI性能优化

  • 布局优化：
    • 减少布局层级（ConstraintLayout替代嵌套）
    • 复用布局
    • 减少层级
    • 延迟加载
    • 避免过度绘制
  • 绘制优化：
    • onDraw中不创建对象
    • 减少invalidate调用
    • 使用clipRect减少绘制区域
    • 硬件加速
  • ListView/RecyclerView优化：
    • ViewHolder复用
    • 分页加载
    • 图片异步加载
    • 滑动时暂停加载

内存优化

  • 内存泄漏：
    • 静态变量持有Activity/Context
    • 非静态内部类/匿名类持有外部类引用
    • 未取消注册（广播、监听器）
    • 资源未关闭（Cursor、InputStream、Socket）
    • 单例持有Context
  • 检测工具：
    • LeakCanary：自动检测内存泄漏
    • Android Profiler：内存分析
    • MAT：堆转储分析
  • 优化方法：
    • 使用Application Context替代Activity Context
    • 静态内部类+弱引用
    • 及时取消注册、关闭资源
    • 图片压缩、缓存
    • 避免在循环中创建对象

启动优化

  • 冷启动：应用进程不存在，从头启动
    • Application.onCreate
    • 首Activity创建
  • 热启动：应用进程存在，从后台恢复
  • 优化方法：
    • 减少Application.onCreate耗时（延迟初始化、异步初始化）
    • 首屏布局简化
    • 避免在主线程做耗时操作
    • 启动页（Splash）预加载
    • 懒加载
  • 启动时间测量：
    • Logcat：Displayed时间
    • adb shell am start -W
    • 方法打点

卡顿优化

  • 主线程阻塞：
    • 耗时操作在主线程
    • 复杂布局
    • 频繁GC
  • 检测工具：
    • Android Profiler：CPU分析
    • Systrace：系统跟踪
    • 严格模式（StrictMode）：检测主线程违规
  • 优化方法：
    • 耗时操作放子线程
    • 异步任务：AsyncTask、HandlerThread、IntentService、RxJava、协程
    • 避免主线程IO操作
    • 减少对象创建，降低GC频率

包体积优化

  • 代码瘦身：
    • ProGuard/R8混淆、压缩、优化
    • 移除未使用代码
    • 减少库依赖
  • 资源优化：
    • 图片压缩（WebP格式）
    • 移除未使用资源（shrinkResources）
    • 资源混淆（AndResGuard）
    • 只保留需要的ABI
    • 只保留需要的语言资源
  • 动态加载：
    • 插件化
    • 动态功能模块（Dynamic Feature）
  • APK分析：
    • Android Studio APK Analyzer
    • 分析各部分大小

电量优化

  • 定位优化：
    • 降低定位频率
    • 使用被动定位
    • 不需要时停止定位
  • 网络优化：
    • 批量请求
    • 缓存数据
    • 使用高效数据格式（Protocol Buffers）
    • 按需连接
  • 唤醒锁（WakeLock）：
    • 及时释放
    • 使用合理的锁级别
  • 闹钟（AlarmManager）：
    • 减少唤醒频率
    • 使用setInexactRepeating允许系统合并
  • JobScheduler/WorkManager：
    • 延迟任务到合适时机（充电、WiFi、空闲）

ANR处理

  • ANR（Application Not Responding）：应用无响应
  • 触发条件：
    • 输入事件5秒无响应
    • BroadcastReceiver 10秒未完成
    • Service 20秒未完成
  • 原因：
    • 主线程耗时操作
    • 死锁
    • Binder调用耗时
  • 分析：
    • /data/anr/traces.txt
    • 主线程堆栈
  • 避免：
    • 主线程不做耗时操作
    • BroadcastReceiver/Service中开子线程
    • 避免死锁
