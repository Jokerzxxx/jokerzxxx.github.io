算法导论

算法导论（原书第3版）

作者：Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, Clifford Stein
全书共8部分35章+附录，798页，系统讲解算法设计与分析的经典教材，涵盖排序、数据结构、动态规划、贪心、图算法、NP完全性等核心主题。

第1部分 基础知识

第1章 算法在计算中的作用

算法定义：

  • 算法是定义良好的计算过程，取一个或一组值作为输入，产生一个或一组值作为输出
  • 算法是解决一个良定义计算问题的工具

算法的重要性：

  • 算法是计算机科学的核心
  • 算法效率直接影响程序性能（时间和空间）
  • 好的算法即使在慢速硬件上也比差算法在快速硬件上快（大规模输入时）

算法分析：

  • 预测算法所需的资源（时间、内存、通信带宽等）
  • 通常关注运行时间
  • 输入规模n作为参数
  • 最坏情况、平均情况、最好情况分析

第2章 算法入门

插入排序：

  • 对于少量元素排序是有效的算法
  • 思想：将每个元素插入到已排序序列的正确位置
  • 时间复杂度：最坏O(n²)，最好O(n)，平均O(n²)
  • 空间复杂度：O(1)，原地排序
  • 稳定排序

循环不变式：

  • 用于证明算法正确性的工具
  • 初始化：循环开始前不变式成立
  • 保持：每次迭代后不变式成立
  • 终止：循环结束时不变式给出正确结果

算法分析：

  • RAM（随机存取机）模型：指令逐条执行，无并发
  • 基本操作：算术、数据移动、控制
  • 运行时间 = 执行基本操作的次数
  • 增长量级：忽略低阶项和常数系数

分治法：

  • 将原问题分解为几个规模较小的子问题
  • 递归求解子问题
  • 合并子问题的解
  • 归并排序是分治法的典型例子

归并排序：

  • 分解：将n个元素分成各含n/2个元素的子序列
  • 解决：递归排序两个子序列
  • 合并：合并两个已排序的子序列
  • 时间复杂度：O(n log n)（所有情况）
  • 空间复杂度：O(n)，非原地排序
  • 稳定排序

第3章 函数的增长

渐近记号：

  • Θ记号（渐近紧确界）：f(n)=Θ(g(n))表示存在正常数c1,c2,n0，使n≥n0时0≤c1g(n)≤f(n)≤c2g(n)
  • O记号（渐近上界）：f(n)=O(g(n))表示存在正常数c,n0，使n≥n0时0≤f(n)≤cg(n)
  • Ω记号（渐近下界）：f(n)=Ω(g(n))表示存在正常数c,n0，使n≥n0时0≤cg(n)≤f(n)
  • o记号（非紧确上界）：f(n)=o(g(n))，对任意c>0存在n0
  • ω记号（非紧确下界）：f(n)=ω(g(n))，对任意c>0存在n0

常见函数分类：

  • 多项式：O(n^k)
  • 对数：O(log n)
  • 指数：O(2^n)
  • 阶乘：O(n!)
  • 增长速度：对数 < 多项式 < 指数 < 阶乘

标准记号与常用函数：

  • 单调性、取整函数、模运算、多项式、指数、对数、阶乘、函数迭代
  • 对数换底公式：log_b n = log_a n / log_a b
  • 阶乘估计（斯特林公式）：n! ≈ √(2πn)(n/e)^n

第4章 分治策略

分治法的递归式：

  • T(n) = aT(n/b) + f(n)
  • a：子问题个数，n/b：子问题规模，f(n)：分解和合并的代价

求解递归式的方法：

  1. 代入法（猜测-验证）：

    • 猜测解的形式
    • 用数学归纳法验证
    • 可通过变量替换简化

  2. 递归树法：

    • 将递归式展开为树，每层节点表示子问题的代价
    • 求和各层代价得到总代价
    • 常用于猜测解的形式，再用代入法验证

  3. 主方法（Master Theorem）：

    • 对于T(n) = aT(n/b) + f(n)，a≥1, b>1
    • 比较f(n)与n^(log_b a)
    • 情况1：f(n)=O(n^(log_b a - ε)) → T(n)=Θ(n^(log_b a))
    • 情况2：f(n)=Θ(n^(log_b a) log^k n) → T(n)=Θ(n^(log_b a) log^(k+1) n)
    • 情况3：f(n)=Ω(n^(log_b a + ε))且af(n/b)≤cf(n) → T(n)=Θ(f(n))

分治法的例子：

  • 归并排序：T(n)=2T(n/2)+Θ(n) → Θ(n log n)
  • 二分查找：T(n)=T(n/2)+Θ(1) → Θ(log n)
  • 矩阵乘法（Strassen）：T(n)=7T(n/2)+Θ(n²) → Θ(n^log2 7)≈Θ(n^2.81)

第5章 概率分析和随机算法

雇用问题：

  • 面试n个候选人，每次面试比当前好就雇用
  • 最坏情况：n次雇用（递增顺序）
  • 平均情况：假设随机顺序，期望雇用次数为ln n（调和级数）

概率分析：

  • 假设输入的概率分布，计算期望运行时间
  • 需要知道或假设输入分布

随机算法：

  • 算法本身做出随机选择，不依赖输入分布
  • 随机排列输入，使所有输入等概率
  • 期望运行时间与输入无关
  • 随机化方法：PERMUTE-BY-SORTING（随机键排序）、RANDOMIZE-IN-PLACE（原地随机交换）

指示器随机变量：

  • I{A} = 1（事件A发生），0（事件A不发生）
  • E[I{A}] = Pr{A}
  • 简化期望计算，将复杂事件分解为指示器变量之和

第2部分 排序和顺序统计量

第6章 堆排序

堆数据结构：

  • 堆是一个数组，可视为完全二叉树
  • 每个节点对应数组一个元素
  • 父节点i的左子节点2i，右子节点2i+1（数组从1开始）
  • 父节点⌊i/2⌋

两种堆：

  • 最大堆：父节点≥子节点，根节点最大，用于堆排序
  • 最小堆：父节点≤子节点，根节点最小，用于优先队列

堆的基本操作：

  • MAX-HEAPIFY：维护最大堆性质，时间O(log n)
    • 比较节点与子节点，若子节点大则交换，递归向下
  • BUILD-MAX-HEAP：从无序数组构建最大堆，时间O(n)
    • 从⌊n/2⌋到1依次调用MAX-HEAPIFY
  • HEAPSORT：堆排序，时间O(n log n)
    • 构建最大堆，将根（最大）与最后元素交换，堆大小减1，维护堆性质
    • 重复直到堆大小为1

优先队列：

  • 维护一组元素，每个元素有键值
  • 最大优先队列操作：
    • INSERT：插入元素，O(log n)
    • MAXIMUM：返回最大元素，O(1)
    • EXTRACT-MAX：取出并删除最大元素，O(log n)
    • INCREASE-KEY：增大元素键值，O(log n)
  • 应用：任务调度、事件驱动模拟、Dijkstra算法、Huffman编码

第7章 快速排序

快速排序思想：

  • 分治法：
    • 分解：选择一个元素作为基准（pivot），将数组分为两部分，左边≤基准，右边≥基准
    • 解决：递归排序两部分
    • 合并：无需合并（原地排序）

PARTITION过程：

  • 选择最后一个元素作为基准
  • 维护两个指针，将小于基准的元素放到左边
  • 最后将基准放到正确位置
  • 返回基准位置
  • 时间O(n)

快速排序性能：

  • 最坏情况：O(n²)（每次划分极不平衡，如已排序数组）
  • 最好情况：O(n log n)（每次划分平衡）
  • 平均情况：O(n log n)
  • 空间：O(log n)递归栈
  • 不稳定排序
  • 实际中通常最快（常数因子小，缓存友好）

随机化快速排序：

  • 随机选择基准元素（或随机交换后选最后一个）
  • 期望运行时间O(n log n)，与输入无关
  • 避免最坏情况

快速排序的优化：

  • 三数取中：选择首、中、尾三个元素的中位数作为基准
  • 小数组用插入排序（n<某个阈值如10）
  • 尾递归优化：减少递归栈深度
  • 三路划分（Dutch National Flag）：将数组分为小于、等于、大于三部分，处理大量重复元素

第8章 线性时间排序

比较排序的下界：

  • 任何比较排序算法在最坏情况下需要Ω(n log n)次比较
  • 证明：决策树模型，n!种排列，决策树高度≥log(n!)=Ω(n log n)
  • 归并排序、堆排序、快速排序都是比较排序，达到下界

计数排序（Counting Sort）：

  • 假设输入元素在0到k范围内
  • 统计每个元素出现次数，计算前缀和确定位置
  • 时间O(n+k)，当k=O(n)时为O(n)
  • 空间O(n+k)
  • 稳定排序
  • 不是比较排序

基数排序（Radix Sort）：

  • 按位排序，从最低位到最高位（LSD）
  • 每一位用稳定排序（计数排序）
  • d位数，每位范围k，时间O(d(n+k))
  • 当d为常数，k=O(n)时为O(n)
  • 稳定排序
  • 应用：卡片排序机、字符串排序、整数排序

桶排序（Bucket Sort）：

  • 假设输入均匀分布在[0,1)区间
  • 将元素分配到n个桶中，每个桶内排序（插入排序）
  • 按桶顺序输出
  • 平均时间O(n)，最坏O(n²)（所有元素在一个桶）
  • 稳定排序
  • 适用于均匀分布数据

第9章 中位数和顺序统计量

顺序统计量：

  • 第i个顺序统计量：集合中第i小的元素
  • 最小值（i=1）、最大值（i=n）、中位数（i=⌈n/2⌉）

最小值和最大值：

  • 找最小值/最大值：n-1次比较
  • 同时找最小和最大值：⌈3n/2⌉-2次比较（成对比较）

选择问题：

  • 找第i小的元素
  • 期望线性时间选择（RANDOMIZED-SELECT）：
    • 基于快速排序的划分
    • 随机选择基准，划分后判断第i小在哪部分
    • 只递归一部分
    • 期望时间O(n)，最坏O(n²)
  • 最坏情况线性时间选择（SELECT）：
    • 5个元素一组，找每组中位数
    • 递归找中位数的中位数作为基准
    • 保证划分至少3n/10 - 6个元素小于基准
    • 最坏时间O(n)
    • 常数因子大，实际中不常用

第3部分 数据结构

第10章 基本数据结构

栈（Stack）：

  • LIFO（后进先出）
  • 操作：PUSH、POP、EMPTY
  • 数组实现，栈顶指针
  • 应用：函数调用、表达式求值、括号匹配、深度优先搜索

队列（Queue）：

  • FIFO（先进先出）
  • 操作：ENQUEUE、DEQUEUE
  • 数组实现，循环队列
  • 应用：广度优先搜索、任务调度、缓冲区

链表（Linked List）：

  • 节点包含数据和指针（指向下一节点）
  • 单链表、双向链表、循环链表
  • 操作：搜索O(n)、插入O(1)（已知位置）、删除O(1)（已知节点）
  • 优点：动态大小、插入删除快
  • 缺点：随机访问慢、额外指针空间

有根树的表示：

  • 二叉树：每个节点有left、right、p（父）指针
  • 左孩子右兄弟表示法：每个节点有left-child、right-sibling指针，表示任意分支树
  • 数组表示（堆）：完全二叉树用数组存储

第11章 散列表

散列表（Hash Table）：

  • 实现字典操作的有效数据结构
  • 平均时间O(1)，最坏O(n)
  • 通过散列函数将键映射到槽位

散列函数：

  • 将键映射到0..m-1的整数
  • 好的散列函数：简单、均匀、快速
  • 除法散列：h(k)=k mod m
  • 乘法散列：h(k)=⌊m(kA mod 1)⌋，A为常数
  • 全域散列：随机选择散列函数，保证期望性能

冲突解决：

  1. 链接法（Chaining）：

    • 每个槽位维护一个链表，冲突元素加入链表
    • 搜索：计算散列值，在链表中搜索
    • 平均搜索时间O(1+α)，α=n/m为装载因子
    • 简单，适用于装载因子大的情况

  2. 开放寻址法（Open Addressing）：

    • 所有元素存在散列表中（无链表）
    • 冲突时探测下一个槽位
    • 线性探测：h(k,i)=(h’(k)+i) mod m
    • 二次探测：h(k,i)=(h’(k)+c1i+c2i²) mod m
    • 双重散列：h(k,i)=(h1(k)+i·h2(k)) mod m
    • 删除需标记为删除（DELETED），不能直接清空
    • 装载因子α<1

完全散列：

  • 静态集合（键不变）的散列方案
  • 两级散列，保证最坏情况O(1)搜索
  • 第一级冲突，第二级用不同散列函数，保证无冲突

第12章 二叉搜索树

二叉搜索树（BST）性质：

  • 左子树所有节点≤根节点
  • 右子树所有节点≥根节点
  • 左右子树也是二叉搜索树

基本操作：

  • 搜索：从根开始，比较键值，向左或向右，O(h)，h为树高
  • 最小值：沿左子节点一直向下，O(h)
  • 最大值：沿右子节点一直向下，O(h)
  • 后继：右子树最小值，或向上找第一个左祖先，O(h)
  • 前驱：左子树最大值，或向上找第一个右祖先，O(h)
  • 插入：搜索找到空位，插入新节点，O(h)
  • 删除：
    • 无子节点：直接删除
    • 一个子节点：用子节点替代
    • 两个子节点：用后继（右子树最小）替代，再删除后继
    • O(h)

随机构建二叉搜索树：

  • 随机插入n个不同键，期望树高O(log n)
  • 期望操作时间O(log n)
  • 最坏情况（已排序插入）退化为链表，O(n)

第13章 红黑树

红黑树性质：

  • 每个节点是红色或黑色
  • 根节点是黑色
  • 每个叶节点（NIL）是黑色
  • 红色节点的子节点都是黑色（无连续红节点）
  • 从任一节点到其叶节点的所有路径包含相同数目的黑色节点
  • 保证树高O(log n)

红黑树的旋转：

  • 左旋：以x为轴，右子节点y提升为x的父节点，x变为y的左子节点
  • 右旋：以y为轴，左子节点x提升为y的父节点，y变为x的右子节点
  • 旋转保持二叉搜索树性质，O(1)

红黑树插入：

  • 按BST插入，新节点着红色
  • 可能违反红黑性质，需修复
  • 三种情况（根据叔节点颜色）：
    • 情况1：叔节点红 → 父、叔变黑，祖父变红，上移
    • 情况2：叔节点黑，新节点是右子 → 左旋转为情况3
    • 情况3：叔节点黑，新节点是左子 → 父变黑，祖父变红，右旋
  • O(log n)

红黑树删除：

  • 按BST删除，若删除黑色节点可能违反性质
  • 四种情况修复（根据兄弟节点颜色和子节点颜色）
  • O(log n)

红黑树的应用：

  • C++ STL的map/set
  • Java的TreeMap/TreeSet
  • Linux内核的进程调度（CFS用红黑树）
  • 完全动态集合，保证O(log n)操作

第14章 数据结构的扩张

顺序统计树：

  • 在红黑树基础上，每个节点存储子树大小size
  • 支持：
    • OS-SELECT：找第i小元素，O(log n)
    • OS-RANK：找元素的排名，O(log n)
  • 插入删除时维护size（旋转时更新）

区间树：

  • 存储区间（low, high）的红黑树
  • 每个节点存储子树最大max-high
  • 支持区间搜索：找与给定区间重叠的区间，O(log n)
  • 搜索策略：若左子树max≥区间low则搜左子树，否则搜右子树

数据结构扩张的方法：

  1. 选择基础数据结构
  2. 确定要维护的附加信息
  3. 验证附加信息可在基本修改操作中维护
  4. 开发新操作

第4部分 高级设计和分析技术

第15章 动态规划

动态规划思想：

  • 适用于最优化问题
  • 特征：
    • 最优子结构：问题的最优解包含子问题的最优解
    • 重叠子问题：递归算法反复求解相同的子问题
  • 方法：
    • 自顶向下带备忘（Memoization）：递归+缓存
    • 自底向上：从小到大求解子问题，存储结果

动态规划步骤：

  1. 刻画最优解的结构特征
  2. 递归定义最优解的值
  3. 自底向上计算最优解的值
  4. 利用计算出的信息构造最优解

经典问题：

  1. 钢条切割：

    • 长度n的钢条，不同长度价格不同，求最大收益
    • r(n)=max(p_i + r(n-i))，i=1..n
    • 自底向上O(n²)

  2. 矩阵链乘法：

    • n个矩阵相乘，不同加括号方式乘法次数不同
    • m[i,j]=min(m[i,k]+m[k+1,j]+p_{i-1}p_kp_j)
    • O(n³)时间，O(n²)空间

  3. 最长公共子序列（LCS）：

    • 两个序列的最长公共子序列
    • c[i,j]=0（i=0或j=0）
    • c[i,j]=c[i-1,j-1]+1（x_i=y_j）
    • c[i,j]=max(c[i-1,j],c[i,j-1])（x_i≠y_j）
    • O(mn)时间

  4. 最优二叉搜索树：

    • 给定键的搜索概率，构造期望搜索成本最小的BST
    • e[i,j]=min(e[i,r-1]+e[r+1,j]+w(i,j))
    • O(n³)时间

  5. 0-1背包问题：

    • n个物品，重量w_i，价值v_i，背包容量W，求最大价值
    • dp[i,w]=max(dp[i-1,w], dp[i-1,w-w_i]+v_i)
    • O(nW)时间（伪多项式时间）

第16章 贪心算法

贪心算法思想：

  • 每一步做出局部最优选择，期望得到全局最优
  • 特征：
    • 最优子结构
    • 贪心选择性质：全局最优可通过局部最优选择达到（无需考虑子问题）
  • 与动态规划的区别：贪心不等待子问题解，直接选择；DP需先解子问题

活动选择问题：

  • n个活动，每个有开始时间s_i和结束时间f_i
  • 选择最多的互不冲突的活动
  • 贪心策略：选择最早结束的活动，然后递归选择之后的活动
  • 证明：存在最优解包含最早结束的活动
  • O(n log n)时间（排序）

贪心算法的正确性证明：

  • 证明贪心选择性质：存在最优解包含贪心选择
  • 证明最优子结构：做出贪心选择后，剩余子问题的最优解与贪心选择合并得到原问题最优解

赫夫曼编码（Huffman Coding）：

  • 数据压缩，根据字符频率构造最优前缀码
  • 贪心策略：每次合并频率最小的两个节点
  • 用最小优先队列实现
  • O(n log n)时间
  • 得到的编码是最优前缀码（平均码长最短）

拟阵（Matroid）：

  • 抽象组合结构，贪心算法可在拟阵上求权值最大独立集
  • 拟阵定义：有限集S + 独立集族I，满足遗传性和交换性质
  • 加权拟阵的贪心算法：按权值降序考虑元素，能加入独立集就加入
  • 例子：图的生成森林（拟阵）、矩阵的线性无关集

任务调度问题：

  • 单位时间任务，每个有截止时间和惩罚（超时惩罚）
  • 求最小总惩罚的调度
  • 可转化为拟阵问题，贪心求解

第17章 摊还分析

摊还分析：

  • 分析数据结构操作序列的平均时间
  • 不涉及概率，保证最坏情况的平均性能
  • 三种方法：聚合分析、核算法、势能法

聚合分析（Aggregate Analysis）：

  • 证明n个操作的总时间上界T(n)
  • 每个操作的摊还代价=T(n)/n
  • 例子：栈的MULTIPOP操作，n个操作总时间O(n)，摊还O(1)
  • 例子：二进制计数器递增，n次递增总翻转O(n)，摊还O(1)

核算法（Accounting Method）：

  • 给每个操作分配摊还代价
  • 当摊还代价>实际代价时，差额作为”信用”存储
  • 信用用于支付后续摊还代价<实际代价的操作
  • 要求任意操作序列的总摊还代价≥总实际代价
  • 例子：栈操作PUSH摊还2，POP摊还0，MULTIPOP摊还0
  • 例子：二进制计数器，置1摊还2，置0摊还0

势能法（Potential Method）：

  • 定义势函数Φ，将数据结构状态映射为非负实数
  • 摊还代价ĉ_i = c_i + Φ(D_i) - Φ(D_{i-1})
  • 总摊还代价 = 总实际代价 + Φ(D_n) - Φ(D_0)
  • 若Φ(D_n)≥Φ(D_0)，则总摊还代价≥总实际代价
  • 例子：栈势=栈中元素数，PUSH摊还2，POP摊还0
  • 例子：二进制计数器势=1的位数，递增摊还O(1)

动态表：

  • 表满时插入触发扩张（分配更大表，复制元素）
  • 表空到一定程度时收缩
  • 摊还分析证明插入/删除摊还O(1)
  • 扩张因子2（装载因子≥1时扩张到2倍）
  • 收缩时机：装载因子<1/4时收缩到1/2（避免频繁扩张收缩）

第5部分 高级数据结构

第18章 B树

B树概述：

  • 平衡多路搜索树，专为磁盘等二级存储设计
  • 节点可包含多个键和多个子节点（分支因子大）
  • 减少磁盘I/O次数（树高低，每次I/O读一个节点）
  • 所有叶节点在同一层

B树性质：

  • 每个节点x有：n_x（键数）、n_x个键、n_x+1个子节点指针
  • 键升序排列
  • 叶节点和内部节点高度差≤1
  • 最小度数t≥2：
    • 除根外每个节点至少t-1个键，至少t个子节点
    • 每个节点最多2t-1个键，最多2t个子节点
  • 根至少1个键（非空树）

B树操作：

  • 搜索：从根开始，在节点键中二分查找，确定子节点，O(h)=O(log_t n)
  • 插入：
    • 搜索到叶节点插入
    • 若节点满（2t-1个键），则分裂为两个各t-1个键的节点，中间键提升到父节点
    • 可在下降过程中提前分裂满节点（保证插入时父节点不满）
    • O(t log_t n)
  • 删除：
    • 更复杂，需保证删除后节点至少t-1个键
    • 情况：从叶节点删除、从内部节点删除（用前驱/后继替代）
    • 子节点键不足时：向兄弟借（旋转）、与兄弟合并
    • O(t log_t n)

B+树：

  • B树的变体，数据只存在叶节点
  • 内部节点只存储键（用于索引）
  • 叶节点用链表链接，支持范围查询
  • 数据库索引常用B+树

B树的应用：

  • 文件系统索引（NTFS、ext4）
  • 数据库索引（MySQL InnoDB用B+树）
  • 适合磁盘存储，减少I/O

第19章 斐波那契堆

斐波那契堆概述：

  • 可合并堆的一种，支持优先队列操作
  • 一系列最小堆有序树的集合
  • 比二项堆有更好的摊还时间（合并、减小键为O(1)摊还）
  • 实际中常数因子大，理论意义重要

斐波那契堆操作：

  • MAKE-HEAP：O(1)
  • INSERT：O(1)，将新节点加入根链表
  • MINIMUM：O(1)，返回最小节点指针
  • UNION：O(1)，合并两个根链表
  • EXTRACT-MIN：O(log n)摊还，删除最小节点，合并子树到根链表，然后合并度相同的树（consolidate）
  • DECREASE-KEY：O(1)摊还，减小键值，若违反堆性质则切断子树到根链表，级联切断
  • DELETE：O(log n)摊还，减小键到-∞，然后EXTRACT-MIN

斐波那契堆的应用：

  • Dijkstra算法和Prim算法中，减小键操作频繁，斐波那契堆可改善理论时间复杂度
  • Dijkstra用斐波那契堆：O(V log V + E)

第20章 van Emde Boas树

van Emde Boas树（vEB树）：

  • 支持优先队列操作的动态集合数据结构
  • 假设元素在全域{0,1,…,u-1}，u为2的幂
  • 操作时间O(log log u)，优于平衡树的O(log n)
  • 空间O(u)（可优化）

vEB树结构：

  • 递归结构：vEB(u)包含：
    • min, max：最小最大元素
    • summary：vEB(√u)，记录哪些簇非空
    • cluster：√u个vEB(√u)，每个存储一个簇的元素
  • 元素x的簇号=⌊x/√u⌋，位置=x mod √u

vEB树操作：

  • MEMBER：O(log log u)，递归查找
  • MINIMUM/MAXIMUM：O(1)，直接返回
  • SUCCESSOR：O(log log u)，先在同簇找后继，否则找下一个非空簇的最小
  • PREDECESSOR：类似
  • INSERT：O(log log u)，递归插入，更新min/max和summary
  • DELETE：O(log log u)，递归删除，更新min/max和summary

vEB树的应用：

  • 整数优先队列，全域不大时
  • 网络路由、整数集合操作

第21章 用于不相交集合的数据结构

不相交集合（Disjoint Set Union, DSU）：

  • 维护一组不相交的动态集合
  • 每个集合有一个代表元素
  • 操作：
    • MAKE-SET(x)：创建只含x的集合
    • UNION(x,y)：合并x和y所在集合
    • FIND-SET(x)：返回x所在集合的代表

链表表示：

  • 每个集合用链表，第一个元素为代表
  • 每个元素有指向代表的指针
  • UNION：将一个链表接到另一个后面，更新代表指针
  • 加权合并启发：短表合并到长表，m个操作总时间O(m + n log n)

有根树表示：

  • 每个集合是一棵树，根为代表
  • 每个节点指向父节点
  • FIND-SET：沿父指针向上到根
  • UNION：将一棵树的根指向另一棵树的根

按秩合并（Union by Rank）：

  • 秩：树的高度上界
  • 合并时将秩小的树接到秩大的树下
  • 保持树低，FIND-SET时间O(log n)

路径压缩（Path Compression）：

  • FIND-SET时，将路径上所有节点直接指向根
  • 后续查找更快
  • 不改变秩（秩只是高度上界）

按秩合并+路径压缩：

  • 摊还时间O(α(n))，α为阿克曼函数的反函数，增长极慢（n<10^600时α(n)≤4）
  • 几乎是常数时间
  • 应用：
    • Kruskal最小生成树算法（检测环）
    • 连通分量
    • 朋友关系网络
    • 图像分割

第6部分 图算法

第22章 基本的图算法

图的表示：

  • 邻接链表：每个顶点维护一个链表，存储相邻顶点
    • 适合稀疏图（E<<V²）
    • 空间O(V+E)
    • 判断边(u,v)存在需O(degree(u))
  • 邻接矩阵：V×V矩阵，a[i][j]=1表示边(i,j)存在
    • 适合稠密图
    • 空间O(V²)
    • 判断边存在O(1)
  • 有向图/无向图、加权图（权重存在链表节点或矩阵中）

广度优先搜索（BFS）：

  • 从源点开始，按距离层次扩展
  • 用队列实现
  • 时间O(V+E)
  • 计算从源点到所有顶点的最短路径（无权图）
  • 生成BFS树
  • 应用：最短路径、连通分量、二分图检测

深度优先搜索（DFS）：

  • 从顶点开始，尽可能深地探索，回溯后继续
  • 递归或栈实现
  • 时间O(V+E)
  • 每个顶点有发现时间d和完成时间f（括号化结构）
  • 边分类：树边、后向边、前向边、交叉边
  • 应用：拓扑排序、强连通分量、环检测、连通分量

拓扑排序：

  • 有向无环图（DAG）的顶点线性排序，若有边(u,v)则u在v前
  • DFS后按完成时间降序排列
  • 或Kahn算法：入度为0的顶点入队，依次输出，更新入度
  • 时间O(V+E)
  • 应用：任务调度、编译依赖、课程安排

强连通分量（SCC）：

  • 有向图中最大的子图，其中任意两顶点互相可达
  • Kosaraju算法：
    1. 对原图DFS，按完成时间降序排列
    2. 对转置图按上述顺序DFS，每棵DFS树是一个SCC
  • Tarjan算法：一次DFS，用low值识别SCC
  • 时间O(V+E)

第23章 最小生成树

最小生成树（MST）：

  • 连通无向加权图中，连接所有顶点且总权重最小的树
  • 有n个顶点的图，MST有n-1条边
  • 通用算法：维护边集合A，每次加入一条安全边（保持A是某MST的子集）

割与轻量边：

  • 割(S,V-S)：顶点的划分
  • 横跨割的边：一端在S一端在V-S
  • 轻量边：横跨割的边中权重最小的
  • 定理：若A是某MST子集，割(S,V-S)不横跨A，则横跨割的轻量边对A是安全的

Kruskal算法：

  • 按权重升序考虑每条边
  • 若边的两个端点不在同一连通分量，则加入（用不相交集合检测）
  • 时间O(E log E)（排序）+ O(E α(V))（并查集）= O(E log V)
  • 贪心算法

Prim算法：

  • 从一个顶点开始，每次加入连接当前树和外部顶点的最小权重边
  • 用最小优先队列维护外部顶点到树的最小距离
  • 时间：
    • 二叉堆：O(E log V)
    • 斐波那契堆：O(E + V log V)
  • 贪心算法

MST的性质：

  • 唯一最小权重（若边权重互异则MST唯一）
  • 割性质、环性质
  • 最小瓶颈生成树：MST是最小瓶颈生成树（最大边权重最小）

第24章 单源最短路径

最短路径问题：

  • 给定加权有向图和源点s，求s到所有其他顶点的最短路径
  • 路径权重=路径上边权重之和
  • 变体：单目的地、单对顶点、所有顶点对

最短路径性质：

  • 最优子结构：最短路径的子路径也是最短路径
  • 三角不等式：δ(s,v)≤δ(s,u)+w(u,v)
  • 上界性质：d[v]≥δ(s,v)，初始化后d[v]只减不增
  • 收敛性质：若s→u→v是最短路径，松弛(u,v)前d[u]=δ(s,u)，则松弛后d[v]=δ(s,v)
  • 路径松弛性质：按最短路径上边的顺序松弛，则最终d正确

负权重边：

  • 允许负权重边（但不能有从源点可达的负权重环）
  • 负权重环：最短路径无定义（可无限绕环减小权重）

Bellman-Ford算法：

  • 对所有边松弛V-1次
  • 再松弛一次，若还能更新则存在负权重环
  • 时间O(VE)
  • 可处理负权重边，检测负权重环
  • 应用：距离向量路由协议

有向无环图（DAG）的最短路径：

  • 先拓扑排序
  • 按拓扑顺序松弛每个顶点的出边
  • 时间O(V+E)
  • 可处理负权重边（DAG无环）

Dijkstra算法：

  • 要求所有边权重非负
  • 贪心：每次选择最短路径估计最小的未访问顶点，松弛其出边
  • 用最小优先队列
  • 时间：
    • 二叉堆：O(E log V)
    • 斐波那契堆：O(E + V log V)
  • 与Prim算法类似（但Dijkstra比较距离，Prim比较到树的边权重）

差分约束系统：

  • 一组不等式x_j - x_i ≤ w_k
  • 可转化为图的最短路径问题
  • 约束图：顶点为变量，边为约束，权重为w_k
  • 求可行解：添加源点，Bellman-Ford求最短路径
  • 若无负权重环则有可行解

第25章 所有结点对的最短路径

所有顶点对最短路径：

  • 求图中每对顶点之间的最短路径
  • 输出V×V距离矩阵

方法1：运行V次单源最短路径：

  • 无权图或非负权重：V次Dijkstra，O(VE log V)（二叉堆）
  • 一般图：V次Bellman-Ford，O(V²E)

方法2：动态规划（矩阵乘法）：

  • 定义L^(m)[i,j]：从i到j最多m条边的最短路径
  • L^(1)=W（邻接矩阵权重）
  • L^(m)=L^(m-1) ⊗ W（类矩阵乘法，加法取min，乘法取加）
  • 重复到L^(V-1)
  • 时间O(V⁴)，用重复平方优化到O(V³ log V)

方法3：Floyd-Warshall算法：

  • 动态规划，允许中间顶点在{1..k}中
  • d^(k)[i,j]=min(d^(k-1)[i,j], d^(k-1)[i,k]+d^(k-1)[k,j])
  • 时间O(V³)，空间O(V²)（可原地更新）
  • 可处理负权重边（不能有负权重环）
  • 可检测负权重环（d[i,i]<0）

方法4：Johnson算法：

  • 适用于稀疏图
  • 重新赋权使所有边非负，然后运行V次Dijkstra
  • 步骤：
    1. 添加源点s，到所有顶点边权重0
    2. Bellman-Ford求s到所有顶点最短距离h[v]
    3. 重新赋权：w’(u,v)=w(u,v)+h[u]-h[v]（保证非负）
    4. 对每个顶点运行Dijkstra（用w’）
    5. 还原距离：d(u,v)=d’(u,v)-h[u]+h[v]
  • 时间O(V² log V + VE)（斐波那契堆），稀疏图优于Floyd-Warshall

传递闭包：

  • 求图中是否存在从i到j的路径
  • 类似Floyd-Warshall，用布尔运算（或/与）替代min/+
  • 时间O(V³)

第26章 最大流

流网络：

  • 有向图，每条边有容量c(u,v)
  • 有源点s和汇点t
  • 流f(u,v)满足：容量限制（0≤f≤c）、流量守恒（除s,t外流入=流出）
  • 流的值|f|=从s流出的净流量

最大流问题：

  • 求从s到t的最大流值

Ford-Fulkerson方法：

  • 基本思想：反复找增广路径，增加流
  • 残留网络：每条边有残留容量c_f(u,v)=c(u,v)-f(u,v)，反向边c_f(v,u)=f(u,v)
  • 增广路径：残留网络中从s到t的路径
  • 沿增广路径增加流（增加量=路径上最小残留容量）
  • 重复直到无增广路径

Edmonds-Karp算法：

  • Ford-Fulkerson的BFS实现
  • 每次用BFS找残留网络中边数最少的增广路径
  • 时间O(VE²)

最大流最小割定理：

  • 割(S,T)：顶点划分，s∈S, t∈T
  • 割的容量=从S到T的边容量之和
  • 最小割：容量最小的割
  • 定理：最大流的值=最小割的容量
  • 三个等价条件：f是最大流 ↔ 残留网络无增广路径 ↔ |f|=某割容量

最大流的应用：

  • 二分图最大匹配（转化为最大流）
  • 多源点多汇点流
  • 顶点容量（拆顶点）
  • 项目选择、棒球淘汰问题

推送-重贴标签算法：

  • 另一种最大流算法
  • 维护超额流（顶点流入>流出）和高度
  • 推送操作：从超额顶点沿残留边推送流
  • 重贴标签操作：增加顶点高度以允许推送
  • 时间O(V²E)（通用），O(V³)（relabel-to-front）

第7部分 算法问题选编

第27章 多线程算法

多线程计算模型：

  • 动态多线程：spawn（创建子线程）、sync（等待子线程完成）
  • 逻辑并行性：计算有向无环图（DAG）
  • 工作（Work）T1：单处理器执行时间（所有顶点计算时间之和）
  • 跨度（Span）T∞：无限处理器执行时间（关键路径长度）

性能度量：

  • 加速比：T1/T_P（P个处理器的加速比）
  • 线性加速比：T1/T_P=P（理想）
  • 并行度：T1/T∞（平均可并行的工作量）
  • Greedy调度器：任意P个处理器，T_P≤T1/P + T∞（上界）

多线程算法例子：

  • 多线程矩阵乘法
  • 多线程归并排序
  • 并行循环（parallel for）

第28章 矩阵运算

矩阵乘法：

  • 朴素算法：O(n³)
  • Strassen算法：O(n^log2 7)≈O(n^2.81)
  • 分治法，7次递归乘法+18次加法
  • 实际中n很大时才优于朴素（常数因子大）

矩阵求逆：

  • 高斯-约当消元法
  • 时间O(n³)（与矩阵乘法同阶）
  • LUP分解求逆

LUP分解：

  • PA=LU，L为单位下三角，U为上三角，P为置换矩阵
  • 解线性方程组Ax=b：
    1. LUP分解
    2. 前向替换解Ly=Pb
    3. 后向替换解Ux=y
  • 时间O(n³)

对称正定矩阵：

  • 所有特征值>0
  • Cholesky分解：A=LL^T，L为下三角
  • 时间O(n³)，常数因子小

第29章 线性规划

线性规划：

  • 目标函数和约束都是线性的
  • 最小化/最大化线性目标函数， subject to 线性不等式约束
  • 标准型：最大化c^T x， subject to Ax≤b, x≥0
  • 松弛型：引入松弛变量转为等式

单纯形算法：

  • 从一个顶点（基本可行解）移动到相邻顶点，改进目标值
  • 转轴操作：交换基本变量和非基本变量
  • 实际中高效，最坏指数时间
  • 终止条件：目标函数系数全≤0（最大化）

线性规划对偶：

  • 原问题（最大化）↔ 对偶问题（最小化）
  • 弱对偶：对偶问题任意可行解≥原问题任意可行解
  • 强对偶：若原问题有最优解，则对偶问题也有，且最优值相等

线性规划的应用：

  • 最大流（可建模为线性规划）
  • 最小费用流
  • 多商品流
  • 资源分配、生产计划

多项式时间算法：

  • 椭球算法：理论多项式时间，实际慢
  • 内点法：多项式时间，实际高效

第30章 多项式与快速傅里叶变换

多项式表示：

  • 系数表示：a_0, a_1, …, a_{n-1}
  • 点值表示：n个点(x_i, y_i)，y_i=A(x_i)
  • 系数表示求值O(n²)（朴素）或O(n log n)（FFT）
  • 点值表示插值O(n²)（拉格朗日）或O(n log n)（FFT逆）

多项式乘法：

  • 系数表示直接乘O(n²)
  • 用FFT：
    1. 系数表示→点值表示（FFT，O(n log n)）
    2. 点值对应相乘（O(n)）
    3. 点值表示→系数表示（逆FFT，O(n log n)）
  • 总时间O(n log n)

快速傅里叶变换（FFT）：

  • 计算多项式在单位复根处的值
  • 分治法：
    • 将多项式分为偶数项和奇数项
    • 递归计算两个子多项式在n/2次单位根处的值
    • 利用单位根性质合并
  • 时间O(n log n)
  • Cooley-Tukey算法

FFT的应用：

  • 大整数乘法
  • 信号处理
  • 卷积计算
  • 图像压缩（JPEG用离散余弦变换，类似FFT）

第31章 数论算法

数论基础：

  • 整除性、最大公约数（gcd）、最小公倍数（lcm）
  • 素数、合数
  • 模运算：a mod n = a - n⌊a/n⌋
  • 同余：a≡b (mod n) 表示n|(a-b)

欧几里得算法：

  • gcd(a,b)=gcd(b, a mod b)
  • 时间O(log min(a,b))
  • 扩展欧几里得算法：求x,y使ax+by=gcd(a,b)

模线性方程：

  • ax≡b (mod n)
  • 有解当且仅当gcd(a,n)|b
  • 用扩展欧几里得求解

中国剩余定理（CRT）：

  • 若n_i两两互质，则方程组x≡a_i (mod n_i)有唯一解mod N=∏n_i
  • 应用：大整数运算、密码学

模幂运算：

  • 计算a^b mod n
  • 反复平方法：O(log b)次模乘
  • 应用：公钥密码（RSA）

素数测试：

  • 试除法：O(√n)
  • 概率测试：
    • Miller-Rabin测试：基于费马小定理和二次探测定理
    • 重复k次，错误概率≤2^(-k)
    • 时间O(k log³ n)

整数因子分解：

  • Pollard rho启发式算法
  • 应用：RSA密码安全性基于大整数因子分解困难

RSA公钥密码系统：

  • 密钥生成：选大素数p,q，n=pq，φ(n)=(p-1)(q-1)，选e与φ(n)互质，d=e^(-1) mod φ(n)
  • 公钥(e,n)，私钥(d,n)
  • 加密：C=M^e mod n
  • 解密：M=C^d mod n
  • 安全性基于大整数因子分解困难

第32章 字符串匹配

字符串匹配问题：

  • 文本T中找模式P的所有出现
  • n=|T|, m=|P|

朴素算法：

  • 对每个偏移s，比较P与T[s+1..s+m]
  • 时间O((n-m+1)m)
  • 最坏O(nm)

Rabin-Karp算法：

  • 用滚动哈希比较模式和文本子串
  • 计算P的哈希，滑动窗口计算T子串哈希
  • 哈希匹配时再精确比较（避免哈希冲突）
  • 期望O(n+m)，最坏O(nm)
  • 适用于多模式匹配

有限自动机：

  • 构造模式P的字符串匹配自动机
  • 状态=已匹配前缀长度
  • 转移函数δ(q,a)=π(P_q a)（最长前缀也是后缀）
  • 扫描文本，状态转移，状态=m则匹配
  • 预处理O(m|Σ|)，匹配O(n)

KMP算法：

  • 利用已匹配信息，避免回溯
  • 前缀函数π[i]：P[1..i]的最长真前缀也是后缀的长度
  • 预处理π数组O(m)
  • 匹配时不匹配则用π回退，不回溯文本指针
  • 匹配O(n)
  • 总时间O(n+m)

后缀数组：

  • 文本所有后缀的排序数组
  • 构造O(n log n)（倍增法）或O(n)（SA-IS）
  • 配合LCP数组，支持多模式查询
  • 应用：全文索引、生物信息学

后缀树/后缀自动机：

  • 更强大的字符串数据结构
  • 后缀树：所有后缀的压缩trie
  • 后缀自动机：最小化的自动机，识别所有子串
  • 支持多种字符串查询

第33章 计算几何学

计算几何基础：

  • 点、线段、多边形
  • 叉积：判断线段转向、点在线段哪侧
  • 线段相交判断：快速排斥+跨立实验

凸包：

  • 包含所有点的最小凸多边形
  • Graham扫描：
    1. 找最低点（y最小，x最小）
    2. 按极角排序
    3. 依次入栈，左转保留，右转弹出
    • O(n log n)
  • Jarvis步进（礼品包装）：O(nh)，h为凸包顶点数
  • Andrew单调链：O(n log n)，按x排序，分别构建下链和上链

寻找最近点对：

  • 分治法：
    1. 按x坐标排序，中线划分
    2. 递归求左右最近点对
    3. 检查跨中线的点对（只需检查中线附近δ范围内的点，每个点比较后续6个点）
  • O(n log n)

线段相交的判定：

  • 判断任意两条线段是否相交
  • 扫除线算法：O(n log n)
  • 用平衡树维护与扫除线相交的线段顺序

其他几何问题：

  • 点在多边形内：射线法（奇偶规则）
  • 多边形面积：鞋带公式
  • 三角剖分
  • Voronoi图
  • Delaunay三角剖分

第34章 NP完全性

多项式时间：

  • 算法运行时间O(n^k)，k为常数
  • P类：多项式时间可解的问题集合

多项式时间验证：

  • 给定一个”证书”，可在多项式时间验证是否为解
  • NP类：多项式时间可验证的问题集合
  • P⊆NP，P=NP?是千禧年难题

NP完全（NPC）：

  • 问题属于NP，且所有NP问题都可多项式时间归约到它
  • 是NP中最难的问题
  • 若任何NPC问题有多项式时间算法，则P=NP

多项式时间归约：

  • 问题A可归约到B：A的任意实例可在多项式时间转化为B的实例，B的解对应A的解
  • 若B多项式可解，则A也多项式可解
  • 若A是NPC且A≤_p B，则B是NPC（需B∈NP）

典型NP完全问题：

  1. 电路可满足性（Circuit-SAT）：第一个NPC问题（Cook-Levin定理）

    • 给定布尔电路，是否存在输入使输出为1

  2. 公式可满足性（SAT）：

    • 给定布尔公式（合取范式CNF），是否存在赋值使公式为真
    • 3-CNF-SAT（每个子句3个文字）也是NPC

  3. 团问题（Clique）：

    • 图中是否存在大小为k的团（完全子图）

  4. 顶点覆盖（Vertex Cover）：

    • 图中是否存在大小为k的顶点集，覆盖所有边

  5. 哈密顿回路（Hamiltonian Cycle）：

    • 图中是否存在经过每个顶点恰好一次的回路

  6. 旅行商问题（TSP）：

    • 完全图中找总权重最小的哈密顿回路
    • 判定版本：是否存在总权重≤k的哈密顿回路

  7. 子集和（Subset-Sum）：

    • 给定整数集和目标t，是否存在子集和为t

  8. 图着色（Graph Coloring）：

    • 是否可用k种颜色着色，相邻顶点不同色
    • 3着色是NPC

NP完全问题的处理：

  • 确定问题是NPC后，不追求精确多项式解
  • 方法：
    • 小规模用指数算法（回溯、分支定界）
    • 近似算法（求近似最优解）
    • 随机算法（概率正确）
    • 启发式算法（实际效果好，无理论保证）
    • 参数化算法（固定参数可解）

第35章 近似算法

近似算法：

  • 对NP完全优化问题，求接近最优的解
  • 近似比ρ(n)：算法解C与最优解C的比值（最大化C/C≤ρ，最小化C/C*≤ρ）
  • 近似方案：对任意ε>0，有(1+ε)近似算法
  • 完全多项式时间近似方案（FPTAS）：运行时间关于1/ε和n多项式

顶点覆盖近似算法：

  • 贪心：任选一条边，加入两个端点，删除所有关联边
  • 近似比2（选出的边不相交，最优至少每条边选一个端点）
  • 时间O(V+E)

旅行商问题近似：

  • 一般TSP：无常数近似比（除非P=NP）
  • 满足三角不等式的TSP：
    • 最小生成树+前序遍历，近似比2
    • Christofides算法：MST+最小权完美匹配+欧拉回路，近似比1.5

集合覆盖近似：

  • 贪心：每次选覆盖最多未覆盖元素的集合
  • 近似比H(d)=1+1/2+…+1/d≈ln d，d为最大集合大小
  • 是该问题的最佳近似比（除非P=NP）

子集和近似方案：

  • 精确算法：动态规划O(n t)（伪多项式）
  • 近似方案：修剪列表（去掉被支配的元素），(1+ε)近似
  • FPTAS：时间O(n²/ε)

最大割近似：

  • 随机算法：每个顶点随机分边，期望割=|E|/2，近似比2
  • Goemans-Williamson算法：半定规划松弛+随机超平面，近似比1.138（0.878近似）

线性规划松弛与舍入：

  • 将整数规划松弛为线性规划（变量取实数）
  • 求解线性规划，将分数解舍入为整数解
  • 常用技术：确定性舍入、随机舍入、对偶舍入
